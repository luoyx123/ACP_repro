# M3 接触接口审计与下一轮修复

目标：核实爬箱失败是否涉及接触定义、oracle点源或控制跟踪问题。不能先认定“landmark错误”，也不能跳过验证直接更换标签后重跑长训练。

## 已完成的离线诊断

使用已完成随机化实验的最终保存轨迹，并保持原数据和模型不变。[HTML审计报告](../../outputs/实验归档/stage1/reports/20261103_contact_audit/index.html)包含九部位接触时序、原始JSON统计和成对实验配置。

- box参考接触onset的手部landmark与环境表面点偏移约62–75mm；足部也可达约50–143mm。两种点具有不同物理含义，存在偏移本身不证明哪种定义正确。
- 最终box代表失败回放为3.16秒。回放时间范围内，左／右手分别有22／20帧参考几何接触，但实际`|Fz|>1N`帧数均为0。
- **逐帧复核证实，这是失稳过程中的撞箱，不能算正确撑箱。** 基座在1.5秒已倾斜18.1°、2秒已倾斜40.4°；右手2.26秒出现291.95N峰值时倾斜46.5°，左手2.98秒出现84.79N峰值时倾斜39.8°。参考左右手onset约2.74／2.78秒，只有右手冲击早于参考；左手发生在同一失败过程的后段。
- **力的表述更正：** `ContactSensor.net_forces_w`只记录法向力的世界坐标向量和，不包含切向摩擦。此前“三维合力”的说法不准确。左右手峰值竖直分量约1.64e-5／9.89e-6N，只能说明记录的法向力主要水平；不能由此推断没有碰撞、没有摩擦支撑，或更换接触判据就能解决失稳。
- 仅有每类任务保存的第一环境代表轨迹，不能将这条轨迹的细节推广到全部1,024环境。时序图显示几何、过滤后的竖直法向力与法向力向量模长诊断；后者没有替代论文的Fz判据。奖励使用未做0.2秒段过滤的传感历史判据，图中的过滤曲线不等于逐步奖励输入。

## 已实现的可验证修改

`ReferenceMotion` 可加载并按身体名称重排 `contact_surface_positions_w`；几何表面点按离散标签保持，不跨不同表面插值。`TensorReference` 增加显式 `contact_position_source`，训练配置字段为 `oracle_contact_position_source`：

- `body_landmark`：缺省值，保留历史实验行为。
- `environment_surface`：从接触onset读取环境witness；缺失字段时直接报错，不静默回退。

**只改变actor的oracle接触位置。** critic参考身体位置、运动学奖励和真实身体landmark定义继续一致；不能把用于跟踪身体的奖励目标整体换成环境表面点。这里是候选修正／对照开关，尚未证明surface更好，也未宣称已修复爬箱。

点源选择、实际yaw变换、相同onset与occupancy、奖励所用landmark不变和surface缺失拒绝回退均有训练环境测试；按名称重排／离散保持在本地测试覆盖。远端数学测试6/6通过，本地35 passed、13 skipped，跳过项仍是缺少相应环境依赖，非收敛失败。

## 接下来执行顺序

1. 先完成[RL配置逐项审计](M3_RL配置审计_20261103.md)，明确对齐项、已知差异和作者未公开项。补齐名义物理／零延迟评估，检查失稳前的控制、力矩饱和、参考动态可跟踪性与坐标时序；不能把摔倒碰撞解释为正确支撑。
2. 再复核箱壁法向、接触位置与时间段：参考几何接触、竖直支撑接触和水平碰撞是否被混在同一标签中；保留论文Fz版本作为对照。
3. 单爬箱做成对试验：相同seed、环境数、参考、PPO、PD与Table S2随机化，只改变oracle点源；从头训练，独立目录。首先小规模物理检查，再用相同训练预算比较完整成功率、CSI是否越过24%瓶颈、2–6秒接触和力矩。之后才做随机化／奖励项的分组消融，避免同时改多项，无法判断原因。
