## PHP 接入结果

发现 40 条低速攀爬与 100 条行走／跑步数据，合计 103,856 原始帧，均为 50 Hz，每条有 10 个箱体地形变体。

核验输入为 XYZ/WXYZ/29 named joints；地形形状为 [boxes,variants,10]，各箱为 XYZ/WXYZ/full XYZ size。使用 PHP 实际 MJCF 对照包内身体位置验证格式，再将相同关节数值放到统一球手 G1-29 上，投影至 23DoF 并生成配套场景、接触标签和成对报告。

两个短样例端到端成功并导出 [攀爬叠加截图](../../outputs/可视化/php/adapter_pilot.png)。全量基线采用每条变体 0，共 140 组；变体 0 没有被认证为原始无扰动场景。

首轮 135 条完成全流程，5 条几何标注查询停滞；后者保留在失败分母。对一个停滞例逐对查询，定位于 `left_ankle_roll_link_collision_0` 与地面在某一帧的有符号距离查询；排除机器人自碰撞对并不能解决这一处，未将该尝试作为修复提交。没有通过改变地形或姿态来掩盖问题。

限时重试复用了 135 条成功结果，5 条仍返回 124 超时，最终保留完整分母。统一入口现用有时限的标注进程包装，成功片段可恢复复用，异常片段按时限失败后继续。故障排查与源／目标几何质量修正是后续独立任务；135 条处理成功片段在当前严格门槛下均为 `needs_repair`，不是已经全部准入。
