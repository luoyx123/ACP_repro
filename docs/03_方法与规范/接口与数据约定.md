# 数据与模块约定（设计稿）

本文件固定模块之间的接口。论文已知值与工程约定分开标明；离线数据、M2 物理环境及 M3 初始 Stage-1 训练循环已实现，Stage 2／3 待实现。当前训练配置和差异见 [M3 记录](../05_实验记录/M3两片段训练.md)。

当前工程机器人关节定义采用 ASAP 的 23 DoF 子集：腰 yaw/roll/pitch 全保留，双腕 roll/pitch/yaw 共 6 DoF 固定零位。源模型为 OmniRetarget 的 G1-29，关节顺序与模型哈希记录在生成资产 provenance 和每条 motion 中，详见 [ASAP23_BASELINE.md](../02_数据集/OmniRetarget关节子集基线.md)。这是工程选型，不能据此断言论文作者使用相同定义；旧 Unitree rev1.0 的 23 维状态不能只凭维数相同直接混用。

## 维度与网络

| 项目 | 论文值 | 依据 |

reference critic 的额外 52 维为 reference base linear/angular velocity 6 + q 23 + qdot 23；另有参考 contact body positions 27 和 flags 9。goal critic 的 3 个标量为水平距离、竖直位移和归一化 episode 时间。critic 的本体状态为当前无噪声单步值，不是 actor 的历史。

### ACP（Table S3）

1. XYZ point embedding：3→16，ELU。
2. 仅高度输入 CNN：1→16→48，两层 5×5/padding=2，ELU。
3. 拼接 point/CNN 为每点 64；Linear 64→96。
4. terrain context：逐点 96→64→64、ReLU，然后 max pool。
5. history/goal/context：442→128→128→96，ReLU。
6. 9×96 learned body embeddings；FiLM 96→64→192 生成 scale/shift，构造 9 个 query。
7. 一层 cross-attention，d=96、32 heads、dropout=0；每个部位输出对 187 点的分布。
8. occupancy head：拼接 attention output 96 和 terrain context 64，160→512→512→512→1，ReLU hidden + sigmoid output。
9. occupancy>0.5 保留目标，否则置零；定量评估 top-k=1，目标严格是观测 terrain point。

论文参数量 786,993；已按上述层宽、带 bias 的线性/卷积层及标准 Q/K/V/output attention 投影独立计算，与该数值一致。实现后仍需核对实际模型参数量，而非只验证 shape。多头 attention 如何聚合成 affordance，以及 FiLM 是 `scale*x+shift` 还是 `(1+scale)*x+shift`，原文未完全明确，需单独记录选择。

MLP baseline：输入 939=375+3+187×3 →285→285，ELU；terrain head 285→1683（9×187），每部位 softmax；occupancy head 285→9、sigmoid。论文参数量 833,322。

## 拟定数据结构（工程约定）

所有物理量使用 SI。磁盘数据明确标注 `world`、`body_yaw`，禁止用模糊的 `local` 替代。

### 单条参考片段

| 字段 | shape | 说明 |
| --- | --- | --- |
| timestamps | [T] | 秒，严格递增 |
| base_position_w / base_quaternion_w | [T,3] / [T,4] | 元数据固定 quaternion 顺序，建议 wxyz |
| base_linear_velocity_w / base_angular_velocity_w | [T,3] / [T,3] | 清楚区分存储坐标和观测变换 |
| joint_positions / joint_velocities | [T,23] / [T,23] | 必须附 joint_names |
| contact_body_positions_w | [T,9,3] | 各身体接触参考点，附 body/link 名称及局部 offset |
| contact_flags | [T,9] bool | 瞬时参考接触；与未来 occupancy 分开 |
| terrain_id / terrain_transform | 标量 / 位姿 | 对齐物理碰撞地形 |

还需 metadata：来源、授权、采样率、机器人模型哈希、关节与部位顺序、地形几何哈希、重定向/标注版本。论文控制器为 50 Hz、PD 为 200 Hz（p.13），但未规定原始动作文件必须存成 50 Hz。原始采样率保留，导出用 `--fps` 指定，本轮训练查询版本取 50 Hz。1.5 秒 future horizon 和 0.2 秒工程接触段过滤按实际 FPS 换算；30 Hz 为 45/6 步，50 Hz 为 75/10 步。SLERP 查询时间只在机器精度范围内夹紧到原片段端点，不因浮点取整漏掉位于网格上的尾帧。

**body 顺序**：left_foot, right_foot, left_knee, right_knee, left_hand, right_hand, left_elbow, right_elbow, pelvis。这是项目约定，rev1.0 语义 frame 映射已实现并校验 FK；接触点定义和碰撞允许对仍需进一步校准。不能认为论文保证使用这一顺序。

### rollout 记录与 planner replay

rollout 至少记录：episode/type/tile ID、时间、当前 root pose、本体观测、goal、planner scan、9 个身体世界位置、接触力（含控制周期内历史）、实际 torque/qdot、终止原因、goal 距离/高度及成功状态。

单个 replay entry 包含：`proprio_history[375]`、`goal[3]`、`terrain_points[17,11,3]`、`target_positions[9,3]`、`target_occupancy[9]`、episode/type/tile ID。存储 onset step、label reason 和版本可帮助排查时序错误。

### yaw 坐标与目标

对查询时刻 t 的 root 世界位置 r 和 yaw ψ：`p_body_yaw = Rz(-ψ) @ (p_world - r)`。仅去 yaw，保持重力对齐；不是用完整 base orientation 的逆旋转。roll/pitch 不改变地形的竖直方向。

goal 水平输入为 `dxy / max(norm(dxy), radius)`，reference radius=0.3m，goal-reaching radius=0.5m；heading wrap 到 [-π,π)。reference goal 从未来 0.5–1.5s 均匀抽取，超过片段末尾则截断（S4）。

scan 网格的 flatten 顺序、机器人朝向、轴符号和高度基准必须统一。footprint 为 x=[-0.8,0.8]、y=[-0.5,0.5]m；tracker 小扫描相应是 [-0.4,0.4]×[-0.3,0.3]m。高度使用 root-relative 的具体观测归一化仍待确定。

## hindsight 标注的预期行为

1. 以竖直接触力超过 1N 判 contact，先过滤少于 10 连续控制步的 segment。
2. episode 完成后反向扫描，找到每时刻每部位未来 75 步内的下一有效 onset。
3. 使用 onset 的身体世界位置，在查询时刻坐标系中变换，检查 footprint；无目标则 occupancy=false、position=0。
4. 原文没有完全约定 onset 时刻自身是否计入当前查询、片段末尾没有完整未来窗口如何处理。实现前冻结边界规则并用短序列验证，不隐藏为经验默认值。
5. reference admission：起始 phase≤0.1 且达到 phase≥0.9；goal admission：同一时刻水平<0.5m 且竖直<0.1m。严格/非严格边界按最终实现记录。
6. contact 原始点究竟取身体 frame 原点、指定末端点还是 manifold 接触点，影响标签/奖励对齐；需统一，不能任意混用。

## 损失、奖励及优化

对每部位/每点：`target_i = softmax(-||h_i-p*||²/(2*0.1²))`。affordance loss 只除以 batch 中有效 body contacts 的数量（分母最少为 1），occupancy BCE 对所有 N×9 项平均；两项相加。建议计算用 log_softmax / BCEWithLogits，避免数值下溢。

Stage 2 切换：`eta_x(u)=clip((u-u_x)/N_ann,0,1)`，x∈{obs,rew}，且 `u_rew>u_obs`。reference 接触三个奖励权重分别 `5(1-eta_rew), 2(1-eta_rew), 1(1-eta_rew)`；planner-contact 权重 `1.5 eta_rew`。Stage 3 全部改 planner contact weight=1.5，关闭参考接触三项（非接触参考跟踪仍限参考环境保留）。

Table 3 还包含：action rate -0.1，二阶 action rate -0.05，torque -1e-5，torque-limit -1e-3，joint-position-limit -10，joint-velocity-limit -1，contact-acceleration -0.01；goal progress 40、stand-at-goal 20；goal-only style 按 terrain mask 激活。具体公式以 **PDF p.19 原表**为准，Markdown 的公式字符不作为执行规范。

PPO（S6）：rollout 24、epochs 5、minibatches 8、clip 0.2、value coeff 1、grad norm 1、gamma 0.99、GAE 0.95；tracker/reference critic 初始 lr 1e-4、KL adaptive；target KL 分阶段 0.02/0.01/0.01，entropy coeff 0.006/0.005/0.002。goal critic 参数见路线 M5。

domain randomization 逐项按 Table S2：动力学多数在仿真启动按环境采样、观测噪声逐控制步；不能每 reset 重采样全部动力学后称为原配置。评估关闭噪声/随机化/延迟。S2 planner scan 的高斯标准差为 **0.03m**（方差 0.03²），不是 0.032m。

## 拟定代码边界

以下目录是后续实现分工，不是目前已存在的功能：

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| `acp/data/` | 动作格式、插值、原始标签、hindsight、replay | NumPy/PyTorch；不依赖 Isaac 启动 |
| `acp/geometry/` | yaw frame、goal、扫描点索引 | 同上 |
| `acp/models/` | tracker/critics/ACP/MLP、loss/decoder | PyTorch |
| `acp/envs/` | G1、地形、观测、奖励、终止、CSI | Isaac Lab |
| `acp/training/` | PPO、dual critics、planner updates、checkpoint | 环境及网络 |
| `acp/evaluation/` | 固定任务、contact events、CI、消融 | checkpoint / rollout |
| `configs/` | paper、small-scale 和实验覆盖配置 | 未知必需字段需校验报错 |

先选并锁定 PPO 基础实现（例如经核对后的 RSL-RL 版本），再改 dual critics/warmup；论文没有披露使用哪个公开 PPO 库，不据作者机构推定。
