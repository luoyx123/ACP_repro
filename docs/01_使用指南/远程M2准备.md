## 跨机器路径与模型

远端本机配置包含 `path_overrides`：将本机原始数据根路径映射到远端副本；`portable_model_root` 指定可再生模型路径缓存。

```bash
# 远端：标准库即可生成模型路径副本
PYTHONPATH=src python3 -m acp.management.portable
```

这会在 `outputs/缓存/portable_models/` 生成需要改路径的 XML/URDF 副本，仅替换网格／包含文件目录等位置属性。原模型、NPZ、manifest 字节保留不变；JSON 消费者通过统一路径解析器选择当前机器的模型副本。前后 SHA-256 和路径映射写入 `outputs/管理/跨机器模型路径副本.json`。

副本的字节哈希与原模型不同。原报告里的模型哈希仍指向原始证据；重新评估与 M2 物理校准应使用当前实际模型并记录其哈希，不能把迁移视作完成了动力学验证。
