## 1. 一句话概括

**【原文级概括】** 本文把**接触**当作感知与全身控制之间的显式中间接口：用自监督的注意力接触规划器（ACP）在地形图上直接预测未来 9 个身体部位（双手、双肘、双膝、双足、骨盆）的接触位置，再由接触条件化的全身跟踪器把接触计划实现为协调的全身运动；运动数据只在训练期充当先验，部署时不输入任何参考，最后用第三阶段 RL 微调把已学会的规划—执行能力自举到数据分布之外的地形。

拆成三句更好记：

1. 接口从"完整参考轨迹"降维成"接触计划"。
2. 运动数据从"要复现的轨迹"变成"训练期的接触样例"。
3. 部署时参考被彻底移除，泛化靠 RL 本身而不是靠扩充参考。

## 3. Introduction 精读（p.1–5）

### 3.1 开头在建立什么对立

**【原文】** 人形机器人在人类环境中需要的能力远超稳定双足行走：跨稀疏落脚点、爬上障碍、在狭窄空间爬行、用上肢支撑。这些**多接触行为本质上不同于常规 locomotion**——不再遵循预设的足部接触模式，机器人必须持续决定其与环境交互的**空间、时间、解剖学分布**。

**【解读】** 开篇就把"接触"的三要素（where / when / which body part）摆出来，这是全文的定义域。之后所有方法设计都在这三个维度上做文章，评估也按 dense-foot / sparse-foot / dense-whole-body / sparse-whole-body 四象限划分（p.6、23）。读后文时用这把尺子对照。

### 3.2 三条既有路线，各自卡在哪

这是 Introduction 的主干，也是最值得抄进笔记的部分：

| 路线 | 代表 | 优点 | 失败模式（原文措辞） |
| --- | --- | --- | --- |
| 纯 RL，无参考 | 四足/双足 rough、sparse、parkour [1–19]；人形 [10,19–31] | 地形泛化好、鲁棒 | 全身控制引入**巨大组合空间**：哪些部位接触、接触的时空分布、其余 DoF 的协调运动学要同时定。仅靠任务目标间接编码 → 需要**大量奖励整形**，微调就会得到截然不同的接触策略 [32] |
| 参考动作模仿 / 跟踪 | DeepMimic [33]；人形大规模动作数据 + 重定向 + 学习式动作先验 [34–43] | 动作自然、协调、拟人，因为参考同时规定了"做什么"和"怎么做" | 跟踪器只有在能为当前环境生成合适参考时才能执行 → **部署时核心问题从控制变成参考生成** |
| 在线生成参考 | 模型式轨迹规划 + 学习控制器 [9,44]；学习式动作生成器/规划器 [45–47]；组合/增广/蒸馏参考 [48–52] | 显式几何推理 + 学习控制的鲁棒性；能表达更丰富的全身行为 | ① 依赖全身规划器 → 计算昂贵、继承建模假设与失效模式；间歇多接触场景下实时生成精确全身轨迹尤其难。② 生成完整轨迹仍是**高维预测问题**；未覆盖的环境配置需要大量数据增广；**运动学可行 ≠ 物理正确**，可接触区域稀疏时小轨迹误差即致命。③ 组合/蒸馏路线在"障碍几何 × 接触位置 × 技能切换"组合爆炸时，构造覆盖性参考越来越难 |

**【解读】** 注意第三条路线被拆成三小类（模型式规划、学习式生成、参考组合/蒸馏），作者对每一小类都给了不同的"死法"。这种"逐类点名"的写法是在为"降维成接触"做唯一性铺垫：三条路都在**完整轨迹**这个高维对象上碰壁。

**【复现】** 表格第三行第三类（[48–52]）是本文最直接的竞争者。做消融或写 related work 时必须能说清：它们靠"更好的参考生成/蒸馏"，本文靠"换接口"。其中 [49] X-Loco、[52] Light-Loco-Parkour 已经做到"部署时无参考"，所以本文的差异化**不在**"部署无参考"，而在**接触这个显式中间表征**。这点很容易被摘要误导。

### 3.3 全文的核心提问

**【原文】**（p.3 左栏）"This raises a fundamental question: **how much of a reference motion does a robot actually need in order to learn generalizable whole-body locomotion?**"

**【解读】** 这是整篇论文的题眼，也是它区别于"再训一个更强的跟踪器"的地方。注意问的是 **how much**（多少信息量），不是 **whether**（要不要用）。答案因此可以是一个"部分信息"：接触。

**【复现】** 这句话直接决定了消融设计：C.1（p.6–7）的 "Stage-1 contact-only tracker vs. 额外输入 52 维参考 root/关节运动学的变体" 对比就在实测"需要多少"。注意该变体与主模型**拿到相同的参考接触命令、训练中也都保留参考运动学奖励**，唯一差别是 actor 多一路运动学输入；结论是 contact-only 每类成功率 ≥98.5%，加运动学输入没有一致提升。复现时如果只跑主实验不跑这条，等于没回答问题。

### 3.4 论证支点：人类证据

**【原文】** 人类走不规则自然地形时不是只对脚下地形做反应，而是**前瞻性地**采集视觉信息来决定未来交互。Matthis et al. [53] 研究自然户外地形行走时的注视与全身运动学，发现人按地形复杂度调整注视行为，同时保持一致的**时间前瞻**策略，并且"对即将到来地形的感知"与"接触位置决策"紧密耦合。

**【解读】** 用一条具身认知/生物力学证据把"该规划什么"这个问题从工程偏好升级为自然事实。它的作用是**合法性**：既然人类也只规划接触点而不预先把全身轨迹定死，那"接触是必要信息"就不是妥协而是正解。

**【存疑】** 这是类比论证，不是证明。它支持"接触是充分且高效的规划变量"，但不排除"接触 + 少量全身线索"更好——这正是 Stage 1 消融要测的。读 Discussion 时注意作者有没有回头限制这个主张。

### 3.5 方案主张：接触是中间表征

**【原文】** 接触已在学习式控制中被反复使用：WoCoCo [23] 用**序列接触目标**条件化全身人形控制；Omar et al. [54] 用接触中心表征做多任务学习；SceneBot [55] 把场景交互接触作为 prompt；OmniContact [56] 提出 **contact flow**（关键身体轨迹 + 时间接触信号）作为执行与组合长程 loco-manipulation 技能的统一接口。

**【原文】** 更关键的是：一旦接触被指定，**可能有很多条合法的全身轨迹**能实现它。手撑在台沿上约束了一个本质交互，却不唯一决定手臂、躯干、腿的轨迹。因此把接触作为**地形感知与全身控制之间的中间表征**——相比完整全身参考轨迹，接触保留了地形交互所需的几何关键信息，同时把"连接这些接触的运动"的自由度留给策略。

**【解读】** 这是全文最重要的一句方法论。用信息论的语言：接触 = 参考轨迹中对任务成败**必要**的那部分（几何硬约束），全身轨迹中的其余部分是**冗余**的（多种实现等价）。降维就是丢掉冗余、保留约束。

**【复现】** 这个论点有一个可检验的推论：同一接触计划下应当能采样出多条不同但都成功的全身轨迹。如果复现出的策略对接触计划极度敏感（换个接触就崩），说明接触没真正成为"约束"而成了"轨迹的一部分"，方法的核心就没实现。

### 3.6 运动数据的角色被改写

**【原文】** 运动数据的用法因此改变：不再是要机器人复现的轨迹，而是**训练期用来学习"哪些身体—环境交互是有用的"**。参考动作提供"有效接触"的样例，RL 决定"在不同机器人状态和地形配置下如何实现这些接触"。策略**不必**保持贴近参考轨迹。部署时参考被**完全移除**：只给机器人状态、地形观测和用户指定目标，策略必须自主决定接触并执行相应全身运动。

**【原文】** 这样，示范为本来困难的全身 locomotion **探索问题**提供了结构，却**不把策略约束在数据集里的全身轨迹分布内**。

**【解读】** "提供结构但不约束分布"是全文的定位句。它同时回答了 3.2 表格里两条路线的病：纯 RL 缺结构（探索难），模仿缺自由（分布内）。

**【复现】** ⚠️ 这是 Introduction 里**最容易被读成"训练也不用参考"**的一句。实际情况：Stage 1/2 的奖励里仍含基座位姿/速度、关节位置/速度、瞬时接触的跟踪项（Fig.2B 明确写出 `R = R_p + R_R + R_v + R_ω + R_C + R_{j,p} + R_{j,v}`，Table 3 注明这些项只在 reference-anchored 环境生效）。"不必贴近参考轨迹"只在**部署接口**和 **Stage 3 的目标到达环境**（`R = R_C + R_t`）成立。若把这句话当成"训练也去掉跟踪奖励"，Stage 1 根本学不起来。

### 3.7 ACP：把 AME 的注意力从"隐式编码"改成"显式规划"

**【原文】** 为了从地形观测自主推断接触，作者建立在 attention-based map encoding（AME）[10,19] 之上。AME 用本体感知条件化对局部地形表征的注意力，让策略选择性提取与当前运动状态相关的地形特征；此前这个机制是**隐式**学到的，被证明会聚焦到与未来落脚点相关的可踩区域。

**【原文】** 本文用的是这个架构的另一种能力：**注意力天然就是显式接触规划的接口**。不再只用注意力把地形编码成隐变量供控制使用，而是用它在地形图上**识别任务相关的接触位置**。具体地，接触规划器以本体感知和用户目标为条件，对地形点做注意力，**直接在地形图上预测显式接触位置**。

**【原文】** 这样"什么时候、在哪里"与环境交互被紧耦合到机器人不断变化的物理状态上；planner 可以随机器人移动而**转移注意力**，按局部几何和当前本体状态为足、手等选择不同地形区域。该设计特别适合稀疏地形——预测接触的小误差就能决定交互可行还是失败；同时**只预测接触而非完整全身轨迹，大幅降低了规划问题的维度**。

**【解读】** 这里是本文在"架构复用"上的巧思所在：AME 原本是"用注意力压缩地图"，本文改造成"用注意力在地图上打点"。物理上同一个 attention 头，语义从 *feature extraction* 变成 *decision output*。这也解释了为什么 ACP 能复用 AME 的网络骨架（Fig.2C：point embedding + height CNN + concat + Linear 96 + multi-head attention + FiLM）。

**【复现】** 三个关键点：
- planner 的输入是 `map scans (L×W×3) + 本体 + goal`，输出 `9×3` 的世界（或 yaw）系接触位置；图注写 375+3 维本体+目标 → 与 [CONTRACTS.md](../../03_方法与规范/接口与数据约定.md) 的维度表一致。
- "大幅降低规划维度"是相对**完整全身参考轨迹**而言的；具体维度差应回查 Methods 后自己算一遍，不要复述"降维"这个词而不给数。
- AME 的 [10] 是 Science Robotics 2025 那篇，[19] 是 AME-2；要复现 ACP 的结构细节应回查这两篇 + 本文 Table S3。

### 3.8 接触表征的四个性质（作者的"为什么更好"清单）

**【原文】** 接触中心表征有四个重要性质：

1. **降低引导的维度**。多条动力学可行的运动可实现同一接触目标，因此接触只约束任务相关交互，策略可自由探索并优化接触之间的全身运动。
2. **接触位置直接以环境为参照表达**，在可行支撑区域稀疏时提供所需的几何精度。
3. **训练变简单**。不必为攀爬、爬行、跨步分别构造奖励，参考接触可通过**同一个接触跟踪目标**引入。
4. **参考轨迹只在训练期用**，部署既不需要动作检索，也不需要模型式或学习式动作生成器；地形多样性可以直接通过 RL 探索，而不必靠对参考轨迹做穷举式人工增广。

**【解读】** 四条分别对应：自由度（1）、精度（2）、工程成本（3）、部署依赖（4）。其中第 3 条最容易被忽略但最实用——它是"一个策略干多种技能"的直接原因：技能差异被吸收进接触计划，而不是吸收进奖励函数分支。

**【复现】** 第 3 条有一个隐式前提：不同技能的接触**标注方式必须统一**（同样的 9 部位、同样的 onset 定义、同样的坐标系）。这正是数据管线里最容易出错、也最值得先做单测的地方，见 [DATA_PIPELINE.md](../../05_实验记录/早期方案/初版数据处理与模型核查.md)。

### 3.9 贡献与三阶段

**【原文】** 本文明确定位的贡献（p.5）：

1. **接触条件化的全身跟踪训练流程**：策略以**接触计划**而非全身轨迹为条件。
2. **接触规划的监督学习形式** + **注意力接触规划器（ACP）**：利用人类动作数据获得丰富多样的接触策略；在崎岖、不连续地形上，给定用户目标，预测 **9 个身体部位**（hands, elbows, knees, feet, pelvis）的接触计划。
3. **在 planner 生成的接触计划上自举的 RL 微调阶段**：连接数据驱动模仿与奖励驱动探索，泛化到未见地形。
4. **基于 LiDAR 的神经建图框架**：能准确刻画细粒度几何，包括梯级这类细小、薄的结构，用于精确全身 locomotion。

**【原文】** 通过三个阶段——接触跟踪、接触规划、RL 微调——框架**逐步降低对运动数据的依赖**，同时保留从示范中获得的协调全身行为。通过隔离任务相关的接触结构，得到一个统一的通用策略，只用**机载感知**就能在未见环境中做多样的、协调的全身运动控制（Figure 1）。

**【解读】** 贡献 1 是"接口"，2 是"规划器"，3 是"训练法"，4 是"感知"。注意贡献 4（建图）与前三者是**正交**的工程模块——它解决"输入的地形图准不准"，不改变方法本身。**【复现】** 因此它是最适合后置的一项（见 REPRODUCTION.md M7）。

**【原文】** 为获得多样且物理可行的全身参考，作者使用**动作重定向管线 [46]**（MGMT）：把人体动作迁移到目标人形平台并考虑运动学约束；得到的轨迹连同**身体—环境接触标签和位置**，作为训练期的接触感知参考。

**【复现】** 这句话是数据链的源头：接触标签来自重定向管线，而不是人工标注。因此"复现接触标签"等于"复现重定向管线 + 其接触定义"，这是本项目当前最优先的阻塞项。

### 3.10 论证链（按作者的行文顺序）

1. 人形在复杂地形需要多接触全身运动 → 这是"接触的时空与解剖分布"问题。
2. 纯 RL：能泛化但探索没有结构，靠奖励整形硬凑。
3. 模仿：有结构但不自由，部署时要先生成参考。
4. 在线生成参考：把"控制问题"换成"高维轨迹预测问题"，还引入规划器的假设与延迟。
5. 组合/蒸馏：能缓解，但随地形组合爆炸而失效 → **需要回答"到底需要参考中的多少信息"**。
6. 人类证据 + 接触被多次证明有效 → 答案是**接触**。
7. 于是：接触做接口 → 数据只在训练期 → 三阶段逐步去掉数据依赖 → 单策略、机载感知、未见地形。

**【解读】** 这是一条标准的"否定三个方案 → 提一个更抽象层 → 在抽象层上重建"的论证。它的强度取决于第 6 步：如果"接触已足够"不成立，整条链就退化成"又一个更好的界面"。所以 Results 里的关键消融是 **C.1 的 contact-only vs. +52 维运动学 actor 输入**（p.6–7）与 **C.2 的 ACP vs. 参数量相近的 MLP**（p.6–7）。

### 3.11 值得背下来的原句

- "how much of a reference motion does a robot actually need in order to learn generalizable whole-body locomotion?"（p.3）
- "the essential information lies not in the complete kinematic-space trajectory, but in its interaction with the environment."（p.3）
- "Once these contacts are specified, however, there may exist many valid whole-body trajectories that realize them."（p.3）
- "demonstrations provide structure to the otherwise difficult exploration problem of whole-body locomotion without constraining the policy to the distribution of full-body trajectories contained in the dataset."（p.3）
- "predicting contacts rather than complete whole-body trajectories substantially reduces the dimensionality of the planning problem."（p.3）
- "attention provides a natural interface for explicit contact planning."（p.3）

### 3.12 读 Introduction 的五个坑

1. **"self-supervised" ≠ 无标签**。标签来自成功 rollout 的 hindsight 接触标注（Fig.2C 图注：*ground-truth contact labels from a motion buffer containing rollout trajectories*），加上 Stage 1 重定向数据自带的 oracle 接触。自主性体现在"标签由机器人自己执行产生"，不是"没有监督信号"。
2. **"不必贴近参考轨迹"有范围**。只对部署接口和 Stage 3 目标环境成立；Stage 1/2 仍有完整运动学跟踪奖励（见 3.6）。
3. **"部署无参考"不是本文独有**。[49][52] 已做到，本文的差异是**接触这个显式中间表征**，不是"无参考"本身。
4. **"9 个部位"是设计选择，不是自然给定的**。足/膝/手/肘/骨盆——膝和肘被显式纳入，说明作者预期跪、撑、肘撑等接触。这直接决定了接触标签必须覆盖这些 link 的真实碰撞接触，而不只是足底。（**【复现】** 若只标足底，方法退化成 footstep planning。）
5. **接触降低的是"规划维度"，不是"控制维度"**。跟踪器仍要输出 23 维动作并处理全身协调；省下的是 planner 的输出空间与监督信号，不是策略容量。

## 4. 追问笔记 #1：底层到底是不是跟踪任务？能换 SuperMimic 吗？

### 4.1 结论先行：是，但只在"训练奖励"这一层

| 层 | 是不是跟踪 | 依据 |
| --- | --- | --- |
| 训练奖励 | **是**：完整运动学跟踪（基座位姿/速度、关节 pos/vel）+ 接触跟踪 | Fig.2B；p.16 "Stage 1 supervises the tracker with ground-truth contact and reference-proprioception targets from the motion-capture corpus" |
| actor 输入 | **否**：无相位、无时间索引、无参考轨迹 | 468 = 375 本体历史 + 63 高度 + 27 接触目标 + 3 goal（p.16） |
| 部署 | **否**：没有参考可跟踪，只有接触计划 + 目标 | 三个阶段 actor 输入都只有 contact targets 与 `g` |

更准确的说法：**它是一条"以接触 setpoint + goal 为条件的反应式（reactive）策略"，用跟踪奖励训练出来**。经典 tracker 跟踪时间参数化的轨迹；这里跟踪**无时间索引的接触 setpoint**。

| | 传统 motion tracker（如 SuperMimic / BeyondMimic） | 本文 tracker |
| --- | --- | --- |
| 训练奖励 | 参考运动学跟踪 | 参考运动学跟踪（**一样**） |
| 部署输入 | 参考轨迹未来帧 / 相位 | 9×3 接触 + occupancy（**无相位**） |
| 时间结构 | 显式相位 `t` | 隐式，由 planner 每步刷新 |
| 技能切换 | 换参考片段 | 换接触计划 |
| 部署时是否跟踪 | 是 | **否** |

### 4.2 三个决定"能不能换优化器"的接口细节

- 接触目标表达在**以 base 为中心、随 yaw 旋转的重力对齐系**，与位置无关，只保留相对几何。
- 每个部位另有一个 **binary occupancy flag**：是否会在规划视界内建立新接触。
- planner 每控制步刷新；occupancy 概率 > 0.5 才保留，否则置零。Stage 2 用 `η_obs` 按环境**整组**切换 oracle/预测接触（不插值），`η_rew` 单独控制接触奖励权重。

**【解读】** occupancy flag 就是本文用来**替代相位变量**的东西。传统 tracker 靠 phase 知道"现在是动作第几帧"，这里靠"我接下来要不要接触、接触在哪"隐含推断自己在动作的哪个阶段。这是全文最巧的工程设计，也是"一个策略干九种技能"的真正机制。

### 4.3 一个值得警惕的推论

既然 Stage 1/2 奖励仍是完整运动学跟踪，tracker 实际学的是：**从接触计划反推参考动作的相位，再复现该相位**。于是 "contact plans alone suffice" 有两种解释：

- (a) 接触捕获了任务本质（作者主张）；
- (b) 接触计划只是参考动作的**充分统计量**，在训练分布内足以恢复相位（更保守的解释）。

C.1 只在 reference-anchored 地形上做（原文 "On reference-anchored terrains, we compare..."），因此**无法区分 (a) 和 (b)**。作者措辞也留了边界："contact plans alone suffice to guide the whole-body skills **in our dataset**"。

真正的判别只能来自 Stage 3 的 goal-reaching 环境——那里没有跟踪项，接触若仍够用，才说明接触不止是相位的代理。**【复现】** 这是最该盯的一条证据链。

### 4.4 SuperMimic 是什么

- 论文：*SuperMimic: Scaling Humanoid Whole-Body Control with One Differentiable World Model*（Liao, Shao, Long, Zakka, Horowitz, Abbeel, Sreenath），CoRL 2026 Oral，[arXiv:2610.28480](https://arxiv.org/abs/2610.28480)。
- 做的事：用**一个可微世界模型**摊销所有动作的跟踪学习。世界模型从标准刚体模拟器的 logged transitions 拟合；世界模型与跟踪策略在同一循环里联合训练；短 imagined rollout 的 BPTT 给策略解析梯度。
- 数字：单卡 3 小时超过 SOTA tracker 基线 128 卡 7 天的 return；>1000× GPU-hour 缩减；129,514 条动作只失败 25 条（基线 179）；两卡 9.8 小时零失败；迁移到实机 G1。
- 公开复现：[UniLab 版](https://github.com/Motphys/Uni-SuperMimic)、[mjlab 版](https://github.com/kaibohex/muscle-supermimic)。

**性质**：它换的是**优化器**（PPO → 可微世界模型 + BPTT），不是**任务定义**。

### 4.5 能不能用来优化这个 tracker：四道检查

| 检查项 | 判断 | 说明 |
| --- | --- | --- |
| 接口兼容 | ✅ 高 | tracker 就是 π(a\|o)、23 维动作；接触计划是外生条件，与 SuperMimic 的参考帧条件同构。世界模型不必吃接触——接触不改变动力学，只改变动作分布 |
| Stage 1 | ✅ 可试 | 奖励以平滑 tracking kernel 为主；数据就是 (o,a,o′,r) 转移，可从 Isaac Lab 记录 |
| Stage 2 | ⚠️ 有真冲突 | `η_obs` 制造的条件分布漂移正是世界模型外推最差之处；hindsight 标签又要求真实物理接触，world model 不可靠 |
| Stage 3 | ❌ 风险最高 | goal env 无 tracking 项；接触奖励用 1N 阈值 / occupancy 门控这类**阶跃函数**，BPTT 梯度几乎处处为零，必须软化 |

三个补充理由：

1. **不能直接 drop-in**。SuperMimic 的策略以参考帧为条件，照搬等于把本文刻意移除的参考又装回去；要先把条件换成 9×3 接触 + occupancy，那时已不是"用现成框架"。
2. **摊销收益与数据规模正相关**。>1000× 是在 129,514 条动作上摊出来的；本文只有 13.2 分钟、123 个参考地形配置。Stage 1 本来也只花 3×4090 约 1 天——省下来是天级，不是数量级。
3. **集成成本落在最脏的地方**。公开复现在 UniLab / mjlab，本文在 Isaac Lab；世界模型必须在**同一个**物理后端拟合才有效，而人形多接触动力学恰是最难学的部分（单边约束、库仑摩擦、冲击）。

### 4.6 目标不同，做法不同

| 真实目标 | 更对症的做法 |
| --- | --- |
| 省 Stage 1 算力 | 先做 PPO 的并行环境/批量 scaling 检查；SuperMimic 只作 Stage 1 的 A/B 候选 |
| 让 tracker 抗接触条件漂移 | **接触条件扰动增广**：位置噪声、随机丢部位、随机翻转 occupancy、延迟一拍——直接对应 Stage 2 的 `η_obs` 需求 |
| 让 planner 损失穿过执行 | 用可微世界模型把 planner→tracker 端到端连起来，这才是 SuperMimic 真正能"升级方法"的位置（属新研究） |

**【工程建议】** 若真做 A/B：固定 Stage 1 数据与地形，PPO vs SuperMimic 各训一套，验收**不只看成功率**，还要看**接触扰动下的成功率衰减曲线**——Stage 2 要的是鲁棒性，不是 in-distribution 精度。
