# 固定双腕后的局部手臂修正

2026-10-29。沿用当前 **23 DoF、半球形手掌、保留三轴腰部** 的模型。用户指出其外形和自由度与论文模型一致；当前继续使用这一基线，不再为了转换动作而更换机器人。此处实现的是本项目的运动学后处理，不称为论文未公开的 Drake IK 实现。

全量 145 条的 ASAP 关节子集基线仍在 `outputs/数据集/omni/asap23_baseline`。本次在三个完整动作、共 **2,886 帧**上实现并验证局部修正、重新生成接触标签及独立评估；没有把这三个样例的结果外推成全部 145 条均已修好。

## 修正方法

`src/acp/quality/repair.py` 读取源 G1-29 和已冻结六腕的 23 DoF 轨迹。仅优化左右肩 pitch/roll/yaw 和肘，共 8 个关节。根位姿、腰部和腿部逐值保持，最后单独校验双脚 FK；肘部已属于可调整部位，不再要求与源 FK 完全相同。

目标同时包含源手中心位置和手掌实际碰撞几何到源最近环境几何的距离。正的源间隙原样作为距离目标，源穿透时以零距离为软目标。距离任务从 30 mm 到 15 mm 平滑引入，避免在接触阈值处突然把手拉向另一个间隙。当前不硬性复现源腕部姿态，也未约束手掌沿环境表面的切向位置；后者另行测量。

求解采用带解析距离雅可比的 SLSQP；包含关节范围、相对基线不超过 0.8 rad、相邻帧速度不超过 URDF 限值的 95%，以及邻帧修正量正则。验证版本使用正则权重 3、前后交替四遍。源手中心权重 20、表面任务最大权重 150、偏离基线权重 0.15；这些是工程参数。

每帧首先求解近距离身体对，随后重新查询**全部候选身体对**的非线性几何距离，有遗漏就补充约束重求解。环境和非局部自碰撞下界取 `min(-2.5 mm, 源同一几何对距离 - 0.5 mm)`，数值验收容差 0.02 mm。这样明确记录源已有重叠，不强行改写腿或整套姿态以清除源模型残差。失败候选拒绝并记录，最终整段另做一次几何验收。

候选自碰撞对排除同一焊接刚体及相隔不超过两个活动关节的结构。这个排除规则仍需模型允许碰撞对校准，不能把“候选对全部通过”解释成所有物理碰撞均已通过。

## 三个完整样例的结果

以下是平滑修正版 `outputs/数据集/omni/arm_contact_repair`，对照为直接冻结手腕的基线。

| 动作 | 帧数 | 源手部近表面状态保留率 | 手掌环境超限步数（前 → 后） | 肩肘最大修正 |
| --- | ---: | ---: | ---: | ---: |
| `climb_03_z_scale_1.0` | 1,009 | 52.75% → 100% | 374 → 0 | 6.06° |
| `climb_01_z_scale_0.9` | 871 | 40.73% → 100% | 312 → 0 | 5.39° |
| `climb_00_z_scale_0.9` | 1,006 | 81.78% → 100% | 79 → 0 | 5.79° |

“近表面”指主手掌几何到环境最近距离在 [−3 mm, 15 mm] 内；“超限”为小于 −3 mm，单位为**手 × 帧**。100% 是源近表面步在修正后仍处于该距离区间，不等于接触位置、法向、支撑力或无滑动均已精确复现。

三个动作根、腰、腿均逐值保持，双脚最大 FK 误差为零；关节速度无超限，最终候选几何约束失败帧为零。验证版所有优化尝试均收敛、无拒绝。手中心相对源的平均位置误差分别由 7.06 / 10.55 / 7.94 mm 降至 1.00 / 1.17 / 0.80 mm。

独立复核见每条 `arm_repair_review.json`：还比较了源最近环境几何上的表面见证点，避免仅看距离而隐藏切向漂移。机器可读汇总副本保存在 [修正指标](../05_实验记录/数据快照/asap23_arm_repair_pilot.json) 和 [独立复核](../05_实验记录/数据快照/asap23_arm_repair_review.json)。

源近表面步的表面见证点误差 P95 分别由 24.91 / 25.98 / 11.82 mm 降至 4.20 / 4.69 / 2.71 mm。全机器人原生环境查询中，三个动作相对源动作**新增**的超 3 mm 帧数分别由 317 / 276 / 69 降至零。修正后仍有 16 / 60 / 6 个全机器人环境超限帧，均与源超限帧重合；这 82 帧不能再算作冻结手腕新增的问题。

### 时间平顺性

第一版虽恢复距离接触，但接触目标硬切换、邻帧正则较弱，手臂加速度最大值达到约 464–868 rad/s²。该版本留在 `outputs/实验归档/omni/omni_asap23_arm_repair` 作对照，不作为推荐结果。

加入表面任务平滑切换、增强邻帧正则并进行四遍优化后：

| 动作 | 最大手臂速度 rad/s（基线 → 修正） | 加速度绝对值 P99 rad/s²（基线 → 修正） | 最大加速度 rad/s²（基线 → 修正） |
| --- | ---: | ---: | ---: |
| `climb_03_z_scale_1.0` | 7.16 → 6.95 | 27.31 → 28.85 | 171.52 → 251.70 |
| `climb_01_z_scale_0.9` | 5.34 → 5.22 | 24.50 → 30.83 | 187.34 → 191.66 |
| `climb_00_z_scale_0.9` | 6.36 → 6.32 | 34.89 → 37.18 | 208.28 → 191.13 |

速度使用逐区间差分，加速度使用这些区间速度的差分；统计包含八个手臂关节。当前没有硬加速度或力矩约束，`climb_03` 的峰值仍有增加，因此尚未宣称动力学可跟踪。

## 复跑和查看

在项目根目录执行：

```bash
PY=/home/lyx/.holosoma_deps/miniconda3/envs/hsretargeting/bin/python
RUN=outputs/数据集/omni/arm_contact_repair

OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 "$PY" src/acp/quality/repair.py \
  --output "$RUN" --workers 3 --passes 4 --smooth-weight 3 \
  --clips climb_03_z_scale_1.0 climb_01_z_scale_0.9 climb_00_z_scale_0.9

OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 "$PY" src/acp/quality/finalize.py --run "$RUN"
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 "$PY" scripts/summarize_arm_repair.py --run "$RUN"

"$PY" scripts/view_omni_trajectory.py --run "$RUN" \
  --clip climb_03_z_scale_1.0 --show-source
```

第一步保存修正轨迹、逐尝试状态和逐帧几何残差。第二步调用 ACP `.venv` 重新生成九部位几何标签及未来目标，再使用 MuJoCo 独立校验并生成质量报告与查看索引。它拒绝把 `--maximum-frames` 开发截断输出当成完整动作。第三步核对标签中的轨迹与求解输出逐值一致，并比较源、子集基线与修正后的几何和时间指标。

查看器 HUD 新增源／修正前／修正后左右手距离和候选几何约束余量。视频仍是 FK 运动学回放，不进行动力学积分。

- 前后并排完整视频：`outputs/可视化/历史回放/asap23_climb03_arm_repair_comparison.mp4`，左为冻结手腕基线，右为平滑修正。
- 单独视频：`outputs/可视化/历史回放/asap23_climb03_before.mp4`、`asap23_climb03_after.mp4`。

源数据、模型与场景沿用基线 manifest 的路径和哈希；迁移机器需准备相应源文件和 mesh，或重新生成基线场景。

## 当前验收边界和后续顺序

现有保守 `quality_summary.json` 仍将三个动作列为 `needs_repair`：它包含源模型也存在的结构自接触、源环境残差，以及尚未校准的 stance／足底速度门槛。这与本次新增手部问题消除是不同的统计。保留原始报告，不通过改阈值把它直接改成训练合格。

接下来先将局部修正扩展到全量 145 条，按源／目标逐对几何增量回归，单独列出不可达和失败帧；然后校准身体允许碰撞对与足底接触定义。对仍有尖峰的片段，加入时间窗口内的加速度／力矩可跟踪约束。最后用 Stage 1 tracker 的成功 rollout 验证动力学，Stage 2 才使用执行中的力接触 hindsight 标签。

测试：ACP 测试 16 通过、5 个本地 MuJoCo 集成测试跳过；本次距离雅可比及实际修正集成测试在 Holosoma 环境单独运行，2 项通过。修正结果的交互窗口、PNG 和完整 MP4 已检查。
