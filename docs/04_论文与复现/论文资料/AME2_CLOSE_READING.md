## 1. 逐段内容总结

### §1 任务需求

在多样化地形上同时做到**敏捷**与**泛化**，需要四项能力：感知与控制的紧耦合、对传感器噪声与遮挡的鲁棒、
通过全身控制获得的敏捷、在稀疏落脚地形上的精确行为。**同时满足这四点仍是核心难题** —— 全文要解决的问题由此定义。

### §2 经典管线

做法：模型控制 + 显式建图 + 状态估计。典型流程是维护状态估计器、由传感器数据构建高程图、再基于地图做模型规划与控制。
在中等结构化地形上的慢速、谨慎行走中有效，但前提是"状态估计准确、地图稠密且变化缓慢"。

三条缺陷（逐层递进）：
1. 依赖精确模型与确定性最优控制 → 对估计与建图误差敏感，**在视觉遮挡与建模假设失效时尤甚**；
2. 高程图更新频率低于控制环，且靠启发式滤波 → **需要按地形调参**，难以形成适应多样地形的通用解；
3. 优化与规划计算开销大 → 限制实机敏捷性。

段末结论：这些局限促使人转向基于学习（RL）的方法——后者更能利用原始传感器数据、能在不确定下工作、能产生更动态的行为。

引用：`[1]–[8]` 经典感知运动管线；`[9]` 状态估计；`[10] [11]` 高程图构建；`[4]` 遮挡下敏感；`[2] [4] [11]` 启发式滤波与低更新率。

### §3 RL + 经典建图

做法：RL + 经典状态估计与建图，把高程图或相关表示作为策略输入。相比纯模型方法能提升鲁棒性与泛化，
但**继承底层估计与建图系统的算力开销与失效模式**。

仿真中处理噪声的两种策略，各有代价：
- **策略 A**：训练时假设"自中心地图完全可观测"，部署时再调整真实建图栈去逼近这个假设。训练简单，
  但一旦出现遮挡就敏感；而且**敏捷的全身接触会违反估计器的建模假设**。
- **策略 B**：把状态估计与建图的噪声重度随机化，使策略在不确定下鲁棒且保守。在密集地形上有效，
  但在**需要很高敏捷性或精确落脚**的地形上表现不佳。

引用：`[12]` RL 综述；`[13]–[26]` 这一类方法；`[27] [28]` 其失效模式的证据；
`[13] [15] [21]` 对应策略 A（理想图假设）；`[14]` 对应策略 B（重随机化）。

### §4 学习式建图

做法：在仿真中训练网络重建地图，再把地图作为策略输入。优点是效率高、适合实时控制。
三条局限：**拟合特定地形分布与传感器配置**、对未见地形泛化有限、**不显式建模不确定度（例如遮挡）**。

引用：`[29]–[34]`。

### §5 端到端/原始传感器策略

做法：把原始外感感知与本体感受直接映射到动作。
- 这类策略在挑战赛道上展示了很高的敏捷性；
- 但泛化能力有限、可解释性差，因为**地形推理被隐式编码在策略里**；
- 更近的"通才"模型从多个专家控制器蒸馏出单一策略，性能强，但**在未见地形上仍泛化有限，且常需在新地形上微调**
  （作者称这一点在其自身的基准实验中有所评估）。

收口（全文定位句）：现有基于 RL 的方法在**敏捷性、泛化性、建图效率、可解释性**之间做取舍，
而不是在统一框架内同时解决这些需求。

引用：`[35]–[47]`；其中 `[36] [38] [42]` 为高敏捷证据；`[48]` 多专家蒸馏的通才策略。

### §6 第一招：AME-2 编码器

提出 AME-2：一个统一 RL 框架，配一个**与控制器联合训练**的注意力地图编码器。编码器建立在 AME-1 的设计之上，流程是：
1. 从高程图提取**局部特征**（逐像素的地形细节）与**全局特征**（地形整体上下文）；
2. 用**全局特征 + 本体感受**给局部特征分配注意力权重；
3. 加权局部特征与全局特征、本体感受拼接，得到"地形感知表示"，送入策略。

两条效果说明：一，策略可以**降低与当前任务无关的局部区域的权重**，从而提升对新地形的泛化；
二，注意力以全局地形上下文为条件，策略能在**不同地形上学到不同的注意力与运动模式**。

此外，采用目标到达（goal-reaching）的运动形式并加以改造，使**同一套奖励函数与训练设置可用于不同机器人**。
编码器与这套训练形式合起来，可训练出带地形感知技能的单一通用策略。

引用：`[15]` AME-1；`[20] [26] [32] [40] [49] [50]` 目标到达形式的来源。

### §7 第二招：学习式高程建图

目的：去掉对经典建图栈的依赖，同时保住泛化。管线：
1. 深度图投影到局部栅格；
2. 用轻量网络（以贝叶斯学习方式训练）预测**局部高程 + 逐格不确定度**；
3. 用里程计把局部预测融合到一致的全局坐标系，得到快速、不确定性感知、能处理遮挡与噪声的表示；
4. 查询自中心高程及其不确定度，作为策略的地图输入。

三个设计理由：一，灵感来自越野导航的神经过程工作——**逐帧预测再融合**，而不是训练时序网络，从而降低数据需求、抑制过拟合；
二，合成随机地形数据，**包括机器人根本不可通行的地形**，以扩大局部地图预测器的训练分布、提升泛化；
三，同一套管线在并行仿真与实机上运行，因此训练期就在线建图，而不是依赖理想化或手工调好的地图。

引用：`[51]` 贝叶斯深度学习中的不确定度；`[52]` 逐帧融合的灵感来源。

### §8 第三招：教师–学生

为训练效率，采用教师–学生：教师先用**真值高程图**训练；学生用**同一套 AME-2 架构**，在"建图在环"的条件下，
同时接受教师监督与 RL 训练。得到的学生策略可直接部署，运行时用的是轻量、不确定性感知的建图，
并保留教师的泛化与敏捷。

引用：`[48] [53]` 教师–学生方案来源。

### §9 实验

在 ANYmal-D 四足与 LimX TRON1 双足上，仿真与实机都做了验证。
结果：控制器表现出很强的敏捷性与对广泛地形的鲁棒泛化；建图管线实时产出高质量高程图，
支撑上述敏捷运动在机载感知与计算下完成。

引用：`[54]` ANYmal-D；`[55]` TRON1。

### §10 四条贡献

1. 提出 AME-2：带注意力地图编码器的统一 RL 框架，实现敏捷且泛化的足式运动。
2. 提出轻量、不确定性感知的高程建图管线：泛化到多样地形、显式建模遮挡与噪声、有助于跨越 sim-to-real 差距。
3. 用教师–学生方案得到可直接部署的控制器，同时保留敏捷、泛化与可解释性。
4. 在四足与双足上、以**同一套训练设置**展示敏捷与泛化的 SOTA 组合。

## 3. 六条需要注意的表述问题（简版）

1. **两套"四维"不对齐**：§1 的需求是紧耦合/鲁棒/敏捷/精确；§5 的取舍轴是敏捷/泛化/建图效率/可解释性。"泛化、建图效率、可解释性"是中途引入的。
2. **"Bayesian learning" 是术语借用**：方法节实际是 β-NLL + stop-gradient 的异方差回归，并明确不用标准贝叶斯融合。
3. **前向引用有反例**：§5 称通才蒸馏"仍泛化有限"，但学生对比表里该对手在带障碍跑酷地形上 99.8% 对本文 89.1%。
4. **"保留教师的泛化与敏捷"是部分保留**：教师测试均值 95.2%，学生 82.4%。
5. **"SOTA 敏捷"无量化定义**：全文未给敏捷的度量，靠"零样本通过最难地形/峰值速度"间接论证。
6. **"single generalist policy" 指"单策略覆盖多地形"**，不是"一个网络覆盖两个机器人"；两个机器人分开训练、地图尺寸不同。

## 4. 论证链

```
四项能力要求
   │
   ├─ 经典建图+MPC ──── 精度/通用/速度 三重受限
   ├─ RL+经典图 ─────── 继承失效；理想图(敏感) vs 重随机化(保守)
   ├─ 学习式建图 ────── 绑定分布；不建模不确定度
   └─ 端到端 ────────── 泛化差；不可解释
   │
"四维取舍，而非统一框架" ← 空位
   │
   ├─ 全局上下文条件化注意力（补泛化）
   ├─ 逐帧高程+方差+赢者通吃融合（补遮挡诚实性）
   └─ 教师–学生（补可部署）
   │
两个平台 × 仿真+实机（补"统一"的证据）
```

## 一、显式建图（4 段）

### A1 早期：模型方法 + 预建图或经典在线建图

多数工作先做**落脚点或轨迹规划**，再用模型跟踪控制器执行；少数直接在可行落脚面上优化**反应式控制器**（不做显式规划）。
优点：有较强的理论保证，在建模假设成立时泛化良好。缺点：模型失配、状态估计不确定、建图误差、计算负担，这四项限制其实机表现。

引用：`[1] [2] [3] [5] [6] [7] [8]` 规划 + 跟踪；`[4]` 反应式控制器。

### A2 RL 作为替代方案（保留强模型成分）

把 RL 当作**模型方法的附加件**：
- **DTC**：给模型规划器配一个 RL 跟踪控制器，提升鲁棒性并保持泛化；但**规划器仍对建图不确定度敏感**，且其建模假设与计算开销限制敏捷性。
- **RLOC**：反过来，用模型控制器去跟踪 RL 规划器；整体性能反过来被**控制器**限制。

这一段的对称结构值得记住：两个工作各自把 RL 放在链条的一端，因此各自的瓶颈也各自落在另一端。

引用：`[12]` RL 用于足式运动；`[21]` DTC；`[22]` RLOC；`[56]` 模型步态规划 + 无模型 RL。

### A3 去掉模型模块，但保留显式图

三种情况：
1. 给定**预建图**时，RL 控制器能做出高敏捷动作；
2. 用**经典在线建图**时，在敏捷性与鲁棒性上超过模型方法，但**敏捷性受建图更新率与质量限制**；
3. 这类控制器常**过拟合训练地形**。

最近的工作（AME-1）证明 RL 能在多样地形上实现泛化运动，但其**敏捷性仍受在线经典建图栈与学习框架的限制**。

引用：`[26]` 预建图下的敏捷；`[13]–[19] [23] [24]` RL + 经典在线建图；`[21]` 过拟合问题的出处；`[15]` AME-1。

### A4 学习式地图

神经网络实时重建自中心地形，供控制器使用。这类工作敏捷性强、已有实机部署；
但**学到的图往往拟合训练分布**，在未见过的、非结构化环境中泛化有限。

本节定位句：本文 = **全 RL 控制器 + 为泛化设计的学习式建图模块**，因此"敏捷性与先前 SOTA 相当，同时获得跨多样地形的泛化"。

引用：`[29]–[34]`。

## 二、原始传感器（3 段）

### B1 目标与三条路线

目标：绕过显式建图的限制。三条路线：
1. **分离式**：视觉模块输出落脚点或轨迹，再由模型控制器跟踪（仍保留感知与控制的分离）；
2. **中间表示**：从原始传感器学出廉价的中间量（射线距离、神经体积记忆），既便宜又能支撑快速控制；
3. **直接从相机 / LiDAR 训练策略**。

引用：`[35]–[39] [41]–[47]` 相机输入；`[40]` LiDAR 点云；`[57]` 分离式（视觉出落脚/轨迹）；`[49]` 射线距离；`[58]` 神经体积记忆。

### B2 单体式设计

单一网络把原始传感器流与本体感受直接映射到关节指令。内部再分两类：
- **特权教师 → 可部署学生**：常把地图作为特权输入，蒸馏出效率高、训练稳的学生；
- **从零学 + 表征学习**：世界模型、特权信息重建等。

当前敏捷通才运动的 SOTA：先用多个**基于建图的教师**，蒸馏成单个直接在原始深度图上运行的通才学生；
该学生能组合各教师技能、可在新地形上高效微调，但**对未见环境的零样本泛化有限**。

引用：`[35] [36] [38] [42] [43] [46] [48]` 特权蒸馏；`[44]` 世界模型；`[41] [45]` 特权信息重建；`[48]` 多教师蒸馏的通才 SOTA。

### B3 本文的取舍

本文也从原始传感器训练网络，但**只用它来做建图**，而不是做"单体式感知—动作策略"。
正因为学习式建图轻量、适合大规模并行仿真，训练期就能跑完整的建图回路，测试期部署**完全相同**的建图，
速度与一致性同时保住。结论：不训练单体策略，也能同时得到敏捷与跨地形泛化。

## 三、学习式建图（4 段）

### C1 目标与经典建图的局限

目标：保留显式地图的**结构与可解释性**，同时克服经典建图的计算与建模局限。
经典建图由几何投影、手工调参的滤波、概率融合组成，能处理相当复杂的真实地形；
但**对敏捷运动太慢**，且必须靠启发式、地形相关的滤波来应付遮挡与传感器噪声。

引用：`[10] [11] [23] [24]`。

### C2 加速路线一：把地形重建放进训练回路

在策略训练循环内或之后训练地形重建模块。这类学习式建图能快速推断局部几何、足以支撑敏捷控制器，
但**训练环境分布窄**，超出训练地形后泛化有限。

引用：`[29]–[34]`。

### C3 加速路线二：不确定性感知的神经建图（越野导航）

技术谱系：**神经过程** → 用它建模高程：网络预测**逐帧局部高程图 + 关联不确定度**，再用里程计做时间融合。
相比端到端的 sensor-to-map 模型，这条路**降低数据需求**，并提升复杂越野环境下的泛化。

但算力不可接受：**每个环境需要超过 13 GB 显存**，无法用于上千并行仿真环境。这是本文自己写建图模块的直接理由。

引用：`[52]` 神经过程做高程；`[59]` 神经过程（技术根）。

### C4 本文的设计

受上述思路启发，做一套面向敏捷足式运动的轻量高程建图：
1. 深度点云投影到局部高程栅格；
2. 轻量鲁棒网络预测局部高程及其不确定度；
3. 用里程计做时间融合；
4. 效果一：抑制传感器噪声；效果二：把**遮挡自然建模为高不确定度区域**；
5. 用自定义数据管线里的大量随机化提升泛化；
6. 结果：轻到能跑大规模并行仿真，快到能支撑部署时的敏捷运动，同时给控制器提供不确定性感知的地形表示。

## 2. 三条胶水（真正把零件粘住的，不是公式而是这三个决定）

1. **一个共享的中间对象**：带逐格方差的高程图同时扮演三个角色——策略的输入、训练时可批量产生的监督信号、可可视化的解释接口。
   三条贡献其实都在服务这一个对象。
2. **一个通道耦合**：建图输出方差 → 学生地图变 4 通道 → 编码器 `d_map` 从 3 变 4 → 教师/学生"同架构"但输入维度不同 →
   表征对齐必须处理这个差异。系统里这是唯一一处"建图改动直接改变了网络结构"的地方。
3. **一次算力重分配**：把神经网络从"策略"挪到"建图"。端到端方案里每一步都很贵；换成一个每环境 < 0.3 ms 的小网络后，
   仿真里能跑完整建图回路，于是"训练期就用真实建图"从不可能变成可选——这才是教师–学生在这里成立的真正原因。
4. 这也解释了为什么这套东西能被 ACP 直接复用：**胶水对象换掉就行**——把“带方差的高程图”换成“带不确定度的接触图”，编码器的注意力从“选地形区域”变成“选接触位置”，其余（逐帧预测 + 融合 + 教师学生 + 目标到达）原封不动。AME-2 里那三处胶水，在 ACP 里对应的是“接触通道 ↔ planner 输出维度”“LiDAR 3 cm 图 ↔ tracker 输入”“教师接触标签 ↔ 学生预测接触”。

## 3. 三处只能推断的地方

- **顺序**：是先有 AME-1 的注意力再想换建图，还是同时考虑？论文按"编码器 → 建图 → 教师学生"排列，但那只是叙述顺序。
- **加全局特征的真实动机**：论文说是"泛化"，但证据（单一地形上 AME-1 反而更好）指向的真实动机是"不被混合地形带偏"。
- **赢者通吃的来源**：论文只说不采用标准贝叶斯融合，没有引用替代方案的出处，可能是自创。

## 4. 按这条链阅读的顺序

想验证这条链，按证据密度读而不是按章节读：

1. 先看**教师架构表**（编码器这一环是否成立）；
2. 再看**建图质量表 + 定性对比**（建图这一环是否成立）；
3. 最后看**学生设计表**（两环接起来后是否还成立）。

如果第 1 环不成立，后两环都没有意义；如果第 2 环不成立，教师–学生只是"用不好用的图训练"；如果第 3 环不成立，
说明前两环的收益在蒸馏里丢掉了。三条证据线各自独立，但结论必须同时成立。

# AME-2 逐节精读（三）：System Overview

## 0. 这一节的定位

整节只有两小节、约三百词，功能是**画方框图 + 列接口清单**，把所有细节都推给 Sec. IV。它要完成三件事：

1. 把问题定义成 POMDP（并说明为什么要用这个框架）；
2. 定义控制接口：频率、动作、观测量、两种地图表示；
3. 用 Fig. 2 把"教师—学生"的系统拓扑钉死。

后面的 IV-A（编码器）、IV-B（非对称 critic）、IV-C（教师学生）、IV-D（奖励）都是在**落实**这一节定下的接口，而不是新增设定。
所以读这一节的目标不是"记住数字"，而是**建立符号表**，后面每出现一个符号都能对上。

---

## 1. A. Formulation：四句话，四个决定

原意逐句：

1. **用 RL 训练能到达位置与朝向目标的地形感知运动策略**。——决定：任务是目标到达（position + heading），不是速度跟踪。
2. **把问题建模为 POMDP，并在并行仿真中用 PPO 优化**。——决定：承认状态不可完全观测；用大规模并行采样换样本效率。
3. **通过最大化目标到达奖励，策略学到能穿越多样地形的敏捷运动技能**。——决定：敏捷不是靠 style reward 或动作先验，而是靠"到点"这个目标本身。
4. **先训练有特权的教师，再把技能迁移给可部署的学生**。——决定：两阶段迁移，而不是用真实建图从零联合训练（原因：在环建图训练慢一半且更吃显存，这条理由在 IV-C 才给出）。

**为什么必须是 POMDP 而不是 MDP**：真实状态包含完整地形几何、精确接触状态、基座真实速度。机载传感器只能看到局部、
被遮挡的高程图，且没有全局定位。于是"状态"实际是**对地形的信念**（由带方差的地图近似）。这也是后面一切设计的根源：
不确定度必须出现在观测里（学生地图 4 通道），而不是被隐式吸收进网络。

**Fig. 2 的四个块**：
```
proprio ──┐
          ├─► 特权教师策略 ──► 关节动作 ──► RL 优化
真值地图 ──┘                            │
                                       │ 监督（动作蒸馏 + 表征对齐）
proprio ──┐                            ▼
          ├─► 可部署学生策略 ──► 关节动作 ──► RL 优化
在线神经地图 ──┘（深度点云 + 里程计）
```
图里的黄色线框是"目标位置 + 朝向"的可视化——提醒这个任务的成功判据是**空间到位**，不是速度指令跟踪。

## 2. B. Controller Inputs and Outputs：逐项

### 2.1 频率层次

| 层 | 频率 | 周期 | 说明 |
| --- | --- | --- | --- |
| 策略 | 50 Hz | 20 ms | 输出一次动作（`dτ = 0.02 s`） |
| 关节 PD | 400 Hz（实机） | 2.5 ms | 每个策略动作期间执行 8 次 PD |
| 仿真 | 未明确 | — | 论文只说"并行仿真"，仿真内部步长/降采样未给 |

**含义**：一个动作对应 8 次 PD 更新，所以动作是"20 ms 内保持不变的位置目标"。
策略并不知道执行器在这 20 ms 内做了什么——这层信息只在执行器模型（ANYmal-D 的执行器网络、TRON1 的直流电机模型）里出现。

### 2.2 动作为什么用 PD 目标而不是力矩

原文只写"**策略动作 `a` 是关节 PD 目标**"。这是一个位置动作空间：
- 优点：对 RL 探索友好，天然有低通特性，sim-to-real 主要只需对齐 $K_p/K_d$；
- 代价：策略无法主动"卸力"（比如踩空瞬间收腿），只能通过位置目标的形状间接实现；
- **【存疑】** $K_p, K_d$ 数值、动作缩放（是否 `q_des = q_nominal + α·a`）、limit 处理，正文均未给，须查代码。

### 2.4 地图的两种表示

# AME-2 逐节精读（四）：IV-A 策略架构与 AME-2 编码器

这是全文**唯一真正提出新结构**的一节（其余都是训练配方与建图）。共 4 段：

| 段 | 内容 |
| --- | --- |
| A1 | 总体架构：本体编码器 + 地图编码器 + MLP 解码器 |
| A2 | AME-2 编码器内部六步 |
| A3 | 与 AME-1 的差别、以及为什么这个差别有用 |
| A4 | 本体编码器可以换：教师用 MLP，学生用 20 步历史 + LSIO |

---

## 1. 逐段内容总结

### A1 总体架构

策略由三块组成：**本体编码器**（把本体感受压成 `e_p`）、**AME-2 编码器**（以 `e_p` 为条件把地图压成 `z_map`）、
**MLP 解码器**（拼接 `e_p` 与 `z_map` 输出动作）。

关键点是**条件的流向**：本体嵌入不是只在最后拼接，它还进入编码器去生成注意力 query。换句话说，
"看地图的哪里"由"我现在的状态"决定——这是 AME 系列与普通 CNN 地形编码器的根本区别。

![image-20261030142553826](../../../../../.config/Typora/typora-user-images/image-20261030142553826.png)

### A2 编码器六步

1. CNN 提取**局部地图特征**；
2. 每个点的坐标经 MLP 得到 **positional embedding**；
3. 二者由另一个 MLP 融合成**逐点局部特征** `F`；
4. 再一个 MLP + **对点做 max pooling** → **全局特征** `g`；
5. `g` 与 `e_p` 经 MLP 得到 **query**；以 `F` 为 **key/value** 做多头注意力 → **加权局部特征**（文中的说法是
   "聚焦重要地形区域的加权局部特征嵌入"，且"基于当前本体状态与全局上下文"）；
6. `g` 与加权局部特征**拼接**成 `z_map`，送入动作解码器。

### A3 与 AME-1 的差别

AME-1 的注意力 query 只由本体感受决定；AME-2 **额外计算全局特征并用它来给局部特征加权**。
作者给出的动机是：在复杂地形上，"运动模式本身应当随地形而变"，因此注意力也需要知道地形上下文。
两个编码器的性能差距放在结果与消融两节。

### A4 本体编码器可替换

架构对本体编码器不作限制，只要产出有效的 `e_p`。因此教师与学生用两种设计：
- **教师**：真值本体可用，直接一个 MLP；
- **学生**：存在各类环境不确定性，堆叠过去 20 步的本体观测（**去掉基座线速度与命令**），用 LSIO 得到
  "机器人状态 + 环境动力学"的时序嵌入；该时序嵌入再与命令一起经 MLP 得到 `e_p`。

## 2. 张量走读（以 ANYmal-D 为例）

```
地图 M ∈ R^{L×W×d_map}          L=36, W=14, N = L·W = 504,  d_map = 3(教师) / 4(学生)
     │                                    │
     │ CNN                                │ MLP(x,y,z) → PE
     ▼                                    ▼
 F_cnn ∈ R^{N×d_c}  ──── MLP 融合 ────►  F ∈ R^{N×d}        （逐点局部特征）
                                              │
                              ┌───────────────┴───────────────┐
                              │ MLP + maxpool over N          │ 作为 K, V
                              ▼                               │
                        g ∈ R^{d_g}                           │
                              │                               │
     e_p ∈ R^{d_p} ──► MLP([g ; e_p]) ──► q ∈ R^{d_q} ──► MHA ┘
                                                              │
                                                     h ∈ R^{d}（单 query ⇒ softmax 池化）
                                                              │
                                          z_map = [g ; h] ∈ R^{d_g + d}
                                                              │
                            a = MLP([e_p ; z_map]) ◄──────────┘
```

要点：

- **`N` 很小**（504，TRON1 为 234），所以注意力在推理上很便宜：单 query、`O(N·d)` 的加权和。
- **query 只有一个**，因此注意力的输出是**一个向量** `h`，不是逐点权重图；逐点权重 `α_j` 只用于可视化
  （这也解释了为什么结果节能画出注意力热图）。
- `e_p` 被用了两次：一次进 query，一次进最后的拼接。
- 教师与学生的 `d_map` 不同，但后续流程完全一致 ⇒ CNN 首层通道数必须是可配置的。

## 3. 四个设计决定与理由

| 决定 | 理由（我的解读，非原文） | 代价 |
| --- | --- | --- |
| 局部特征用 **CNN** | 地图是规则栅格，局部卷积天然表达"坡度、台阶边缘、梁宽"这类局部几何 | 感受野有限，需要全局特征补 |
| 每点单独算 **positional embedding** | 让网络知道"这个特征在地图的哪个位置"，否则平移后的同样地形无法区分优先级 | 参数与计算随 N 线性增长 |
| 全局特征用 **MLP + max pooling** | max pooling 选出**稀疏的显著点**（障碍边界、高台面、梁中心），正好对应"地形类型的特征点" | 丢弃了全局统计量（均值/方差） |
| attention 用 **单个 query** | 把"看哪里"压成一次软选择，成本低；query 由 `[g; e_p]` 生成 ⇒ 地形上下文参与选择 | 只能提取一个"视角"，无法并行关注多个区域 |

**这四条合起来的效果**：CNN 提供细节，max pooling 提供"地形类型"的几个关键点，注意力用这些关键点决定哪些细节重要。
三者缺一：只 CNN → 无地形上下文；只全局 → 丢失细节；无注意力 → 细节与上下文简单拼接，网络要自己学加权。

## 4. 教师与学生的本体编码器

| | 教师 | 学生 |
| --- | --- | --- |
| 输入 | 当前时刻无噪声本体（含 `v_b`） | 过去 **20 步**本体（**去掉 `v_b` 与命令**） |
| 结构 | 普通 MLP | **LSIO** 时序编码 + MLP |
| 输出 | `e_p` | `e_p`（与时序嵌入和命令共同产生） |
| 目的 | 学出技能上限 | 处理真实传感的不确定性与历史依赖 |

**为什么学生要历史**：真实系统里基座速度不可靠、接触与地形交互有延迟效应，单帧观测无法判断"刚刚发生了什么"，
（例如"我正在下落" vs "我刚落地"）。历史 + 时序编码把这类信息补回来。

**为什么去掉 `v_b` 与命令**：`v_b` 在实机上由里程计给出，噪声大且有延迟（方法节给的量化：20 ms 内 1 cm 漂移 ≈ 0.5 m/s 速度误差）；
命令不放进历史，是为了让"当前指令"单独进入、不与历史混淆。

**【存疑】** LSIO 的具体层结构（长/短两条路径各是什么、如何融合）正文未给，只有引用；须查原论文或代码。
另外"堆叠 20 步"是**在编码器之前**做（张量形状 `20 × d_obs`）还是编码器内部做，也未明确。

# AME-2 逐节精读（五）：IV-B 非对称 actor–critic + IV-C 教师–学生

这两节必须一起读：**它们合起来是在设计"三个智能体的信息集"以及它们之间的信息流**。
IV-B 决定谁看得见什么，IV-C 决定信息怎么从教师流向学生。分开看都像工程细节，合起来才是方法论。

```
            ┌──────────── 信息流 ────────────┐
教师 actor ──┤ 动作蒸馏 + 地图嵌入对齐        ├──► 学生 actor
（真值图、    │                                │   （在线建图、
  无噪声本体）└────────────────────────────────┘    20 步历史）
      ▲                                              ▲
      │ advantage                                    │ advantage
      └──────────── critic（共享，信息最全）──────────┘
```

---

## 一、IV-B：非对称 actor–critic

### B1 为什么 critic 不用注意力

原文给了两条理由：critic **不需要泛化**到训练地形之外；在 `L×W` 个局部特征上**优化** MHA 很贵。
于是改用 MoE，理由是"拟合能力强、优化高效"。并补一句关键论断：**用 MoE 做 actor 得不到泛化的教师**。

【解读】这段其实说出了全文最重要的架构判断：**泛化来自归纳偏置（地图的空间结构 + 注意力），不来自容量**。
MoE 容量大但丢掉了"地形是二维栅格"这个先验，所以在训练地形上拟合得很好（教师表里 95%+），
一换地形就塌（测试均值 45.0%）。而 critic 只需要在训练分布上把 return 拟合准，容量正是它要的。

【解读】"优化贵"要理解为**反传贵**而不是推理贵：actor 每步只前传一次，critic 每步都要反传，
而每步有约 504 个点 × 4800 个环境。MoE 的路由使每个 token 只经过少数专家，计算稀疏。

### B2 给 critic 更多信息、给教师更少信息

critic 在教师 actor 的输入之上**额外获得每个 link 的接触状态**；而**教师 actor 拿不到**接触状态。原文给的理由：
1. 不给接触信息也能训出鲁棒、泛化的教师；
2. **教师与学生之间的信息差越大，学生训练越容易受损**。

【解读】第 2 条是这一节最值得记住的原则（引的是"student-informed teacher training"那条线）：
教师一旦使用了学生看不到的信息（例如精确接触），它的动作里就会隐含学生无法复现的依据；
学生只能"照着做对的答案，但看不到为什么"，蒸馏时就会出现不可约的误差。
所以**教师的信息集要"刚好比学生多一点"**：多到能学得比学生好，少到学生能追上。

**对称增强只给 critic**：用左右对称增强提升样本效率与动作风格，但不给 actor（省 actor 的优化开销）。
【解读】这是在"不增加 actor 成本"的前提下注入对称先验：增强作用在价值函数上，再通过 advantage 间接塑造策略。

**critic 在教师与学生之间共享**：因为它的输入是特权量（真值图、无噪声本体、接触），两个阶段都能用；
分开建会白烧显存。

## 二、IV-C：教师–学生

### C1 为什么用教师–学生

原文先承认：直接用建图管线从零训学生**是可行的**；但在环建图仿真只有真值图**约一半的速度**、且**显存显著更高**。
所以这是**效率选择**，不是能力限制。

【解读】这句话很重要：它说明"教师–学生"在这篇里不是"必须的蒸馏"，而是"付不起在环训练成本的替代方案"。
对复现的含义：如果算力允许，直接训学生也是一种合法（甚至更简洁）的路线，只是论文没有验证它。

### C2 三项损失，各治一个病

$$
\mathcal{L}=\underbrace{\mathcal{L}^{\text{PPO}}}_{\text{在自己观测分布下自我修正}}
+\lambda_a\underbrace{\big\|\pi_\theta(\mathbf{o})-\pi_{\theta_T}(\mathbf{o})\big\|^2}_{\text{冷启动，}\lambda_a=0.02}
+\lambda_r\underbrace{\big\|\mathbf{z}^{S}_{map}-\mathbf{z}^{T}_{map}\big\|^2}_{\text{对齐地形表征，}\lambda_r=0.2}
$$

三项目的对应关系（结合消融表）：

| 去掉哪项 | 测试均值 | 掉得最狠的地形 | 说明 |
| --- | --- | --- | --- |
| 无 RL（只蒸馏 + 表征） | 60.7% | Test1 46.9%、Test4 46.0% | 只能模仿，不能在自身噪声观测下修正 |
| 无表征损失 | 73.6% | Test3 89.1%→69.5% | 动作学得像，内部地形表征没对齐 |
| 完整 | 82.4% | — | — |

【解读】三项的分工可以这样记：
- **蒸馏**解决"从零到会"（否则 RL 在复杂地形上探索不出来）；
- **表征**解决"学到同样的地形理解"（否则换个地形，内部表示漂移）；
- **PPO** 解决"在自己的观测分布下修正"（否则学生只能复现教师的动作，无法补偿建图噪声）。

**为什么表征损失有效**：动作蒸馏只约束**输出**。学生完全可以用一套不同的内部表示产生相同的动作——训练地形上够用，
换地形就露馅。对齐 `z_map` 是**过程监督**而非结果监督，所以迁移性更强。这是"结果监督 < 过程监督"的一个干净实例。

**为什么前几次迭代关掉 PPO**：早期学生策略很差，advantage 估计噪声大，PPO 梯度方向不可靠；此时蒸馏是唯一稳定的信号，
用大学习率快速对齐，再放开 PPO。这是"损失函数层面的课程"。

**一个语义上的限制（对我前面判断的修正）**：
教师的图是 3 通道（无不确定度），学生是 4 通道。`z_map` 的维度与输入通道无关（CNN 首层吸收通道差），
所以**维度上对齐没问题**；但**语义上有问题**——教师的嵌入里不可能含"不确定度"，
学生却被要求匹配它。结论：**表征损失教不了学生怎么用 `u`，`u` 的使用只能靠 PPO 自己学**。
这一点也解释了为什么学生仍会在遮挡区失败（结果节里的失败模式）。

## 三、B + C 合起来的三条设计原则

1. **信息集分层**：教师（特权但克制）→ 学生（机载）→ critic（全知）。critic 全知是为了降方差，教师克制是为了可蒸馏。
2. **泛化靠归纳偏置，不靠容量**：actor 用注意力（带地图空间先验），critic 用 MoE（只拟合）。这一条有直接证据（MoE 教师测试 45%）。
3. **监督分层**：动作（结果）→ 表征（过程）→ RL（自身分布）。三者缺一，消融各掉 20 / 9 个百分点量级。

# AME-2 逐节精读（六）：IV-D Environments

这是全篇"可直接抄参数"最多的一节，四部分：奖励（表 I + 式 1–5）、终止、地形与课程、域随机化。

## 1. 奖励：三类，各管一件事

| 类别 | 目的 | 代表项 |
| --- | --- | --- |
| 任务奖励 | 诱导目标到达行为 | 位置/朝向跟踪、朝目标移动、到点站立 |
| 正则奖励 | 稳定性与安全 | 基座横滚角速度、关节正则、动作平滑、接触力、link 加速度、不良事件 |
| **仿真保真奖励** | 惩罚"接近极限的关节状态" | 关节位置/速度/力矩限幅 |

第三类容易被忽略但很重要：它不是为实机安全，而是**防止仿真器在极限状态产生非物理行为被策略利用**——
极限附近 PhysX 与执行器模型的建模误差最大，策略一旦学会"贴着极限跑"，sim2real 就会崩。

### 1.1 四个任务项

位置跟踪（引 [49] 的形式）：

$$
r_{\text{pos}}=\frac{1}{1+0.25\,d_{xy}^2}\cdot t_{\text{mask}}(4),\qquad
t_{\text{mask}}(T)=\frac{1}{T}\,\mathbb{1}(t_{\text{left}}<T)
$$

朝向跟踪：

$$
r_{\text{hdg}}=\frac{1}{1+d_{\psi}^2}\cdot t_{\text{mask}}(2)\cdot\mathbb{1}(d_{xy}<0.5)
$$

朝目标移动（稠密引导项）：

$$
r_{\text{move}}=\mathbb{1}\Big(d_{xy}<0.5\ \lor\ \big(\cos\theta_{\mathbf{v},\text{goal}}>0.5\ \land\ 0.3\le\|\mathbf{v}_{xy}\|\le 2\big)\Big)
$$

到点站立：

$$
r_{\text{stand}}=\mathbb{1}(d_{xy}<0.5\land d_{\psi}<0.5)\cdot\exp\!\Big(-\frac{d_{\text{foot}}+d_g+d_q+d_{xy}}{4}\Big)
$$

其中 `d_foot` = 未接触足数 / 总足数；`d_g = 1−[g_b]_z²`（= sin²(倾角)，即倾角的平方惩罚）；`d_q` = 关节相对站立参考的平均偏差。

### 1.2 `t_mask` 的 1/T 因子：总预算归一化

末段窗口 `T` 内有 `T/dτ` 个控制步，每步贡献 `w·dτ·(1/T)·kernel`，整段求和：

$$
\sum_{\text{末}T\text{秒}} w\,d\tau\cdot\frac{1}{T}\cdot\text{k} = w\cdot\text{k}
$$

**整个末段窗口的总奖励 = `w × kernel`，与 `T` 无关。** `T=4` 与 `T=2` 只是改变"多晚才开始要求到位"，
不改变奖励总量。这是这个掩码设计最精巧的地方——换机器人时改 `T` 不会破坏奖励尺度。

### 1.3 位置核的宽度是算过的

`1/(1+0.25 d²)`：`d=0→1.00`，`1 m→0.80`，`2 m→0.50`，`4 m→0.20`，`6 m→0.10`。
系数 0.25 使 2 m 处恰好半衰——而 2 m 正是 actor 命令的截断距离，4 m 正是课程降级判据里的"平均起点距离"。
三个数字互相呼应，不是随意取的。朝向核 `1/(1+d²)`：`0.5 rad→0.80`，`1 rad→0.50`。

### 1.4 权重与有效量级

表 I 的权重全部乘 `dτ = 0.02 s`。换算成"每步有效值"：

| 项 | 表中权重 | 每步有效值（d=0 时） |
| --- | --- | --- |
| 位置跟踪 | 100 | **2.0** |
| 朝向跟踪 | 50 | **1.0** |
| 朝目标移动 | 5 | 0.1 |
| 到点站立 | 5 | 0.1 |
| 提前终止 | −10/dτ | **−10（一次性；按表头 ×dτ 约定）** |
| 不良事件 | −1/次 | −0.02（若也乘 dτ） |
| 基座横滚角速度 | −0.1 | −0.002 / rad²s⁻² |
| 关节正则 | −0.001 | −2×10⁻⁵ |
| 动作平滑 | −0.01 | −2×10⁻⁴ / rad² |
| 接触力超重 | −10⁻⁵ | −2×10⁻⁷ / N² |
| link 加速度 | −0.001 | −2×10⁻⁵ |
| 关节位置限幅 | −1000 | −20 / rad（越界时） |
| 关节速度限幅 | −1 | −0.02 / (rad/s) |
| 关节力矩限幅 | −1 | −0.02 / Nm |

读法：**任务项 O(1)/步，正则项 O(10⁻²~10⁻⁵)/步**，这也印证了原文那句"正则项比任务项小 1–2 个数量级，因此不需要大量调权重"。

**早停项为什么要写成 `−10/dτ` 而不是 `−10`**：表头是"Weight (×dτ)"，即项值 = 权重 × `dτ` × 表达式。
于是 `(−10/dτ)·dτ·1 = −10`——写成分式正是为了让**惩罚与控制频率无关**。按字面"权重 × 表达式"直读会得到 `−500`，
两者差 50 倍，必须查代码确认。若取 `−10`，一次摔倒约等于 20 步满分位置奖励（0.5/步），是常见的量级；
若取 `−500`，一次摔倒相当于整回合位置奖励预算的 5 倍，策略会极度保守——从论文强调硬件保护看也不是不可能。

### 1.5 七个"不良事件"（每次 −1）

| 事件 | 判据 | 真正的用意 |
| --- | --- | --- |
| 转太快 | 偏航角速度 > 2.0 rad/s | **保护里程计**（快速旋转会让 SLAM 漂移） |
| 平地腾空 | 高差 < 30 cm 时四足同时离地 | 抑制无意义跳跃 |
| 非足端接触 | 任意非足端 link 接触 | 允许攀爬时的必要接触 |
| 非足端接触切换 | 从无接触变为接触 | 与上一条分开，抑制"反复试探" |
| 绊倒 | 水平接触力 > 竖直接触力 | 抑制用小腿/膝盖硬顶 |
| 滑移 | 接触中 link 仍有位移 | 抑制蹭着走 |
| 自碰撞 | 机器人 link 之间碰撞 | 安全 |

注意"非足端接触"与"非足端接触切换"被**刻意分开**：前者允许静态支撑（攀爬必需），后者抑制反复开关。

### 1.6 为什么不定落脚点

原文明确与三项工作划清界限：**不在稀疏地形上奖励或惩罚落脚位置**，而是对所有 link 统一建模，让全身接触自然涌现。
理由两条，第二条最关键：**落脚规则在地形之间不可通用**——四足攀爬需要膝接触与近边缘落脚，稀疏地形上近边缘落脚却有害。
同一条规则无法同时服务两种地形，所以"不规定"反而是通解。

## 2. 终止：四条，本质是安全包络

| 条件 | 判据 | 用意 |
| --- | --- | --- |
| 姿态翻转 | `|g_x|>0.985`、`|g_y|>0.7`、`g_z>0` | 已经倒地 |
| 基座碰撞 | 基座接触力 > 整机重量 | 躯干撞地/撞墙 |
| 大腿加速度 | 四足 60 / 人形 100 m/s² | **保护硬件**，取自犬/人生物力学数据 |
| 停滞 | 5 s 内移动 < 0.5 m 且离目标 > 1 m | 避免在局部极小值空耗 |

大腿加速度这条是"约束即奖励"的典型：作者没写 impact-reduction 奖励，只把"落地太硬"变成终止条件，
策略自己学会收腿/用膝缓冲。

## 3. 地形与课程

**训练地形比例**：dense 25%（rough、stair up、stair down、boxes、obstacles 各 5%）、
climbing 30%（climb up 20% + climb down 5% + consecutive 5%）、sparse 45%（stones 30% + gap 5% + pallets 5% + beam 5%）。
sparse 占比最高，因为它是泛化的主要考察面。

**课程机制**（两端不对称）：
- **升级**：成功率指数滑动平均 > 0.5 且当前回合确实到达目标；
- **降级**：不看过没过，而看"是否还在离目标 > 4 m 处"（≈平均起点距离）——**进度判据**而非成功判据，
  解决"慢机器人从不成功但一直在进步"的问题；
- 满级后随机重置难度，保持分布多样性。

**两个额外课程**：教师训练前 20% 迭代内，建图噪声从 0 线性升到最大；同时初始朝向从"正对目标"扩到 `[−π, π]`。
前者先学"用干净图"再学"用脏图"；后者消除"开局总是朝目标"的捷径。

**地形参数**（附录 A，复现最有用的一组数）：rough 噪声 ±0→±0.2 m（人形 ±0.15）；楼梯坡度 5°→45°；
boxes 0.05→0.4 m（人形 0.3）；obstacles 密度 0→0.5 m⁻²；climb up 坑深 0.1→1.0 m（人形 0.48）；
climb down 台高 0.2→1.0 m（人形 0.88）；gap 0.1→1.1 m（人形 0.6）；pallets 梁宽 0.4→0.16 m；beam 梁宽 0.9→0.18 m。

**稀疏地形的关键技巧**：一半地形加**物理地面**，另一半加**可见但无碰撞的虚拟地面**（高度 −1.5 ~ −0.35 m 随机），
阻止机器人绕开稀疏结构直接走地面。

## 4. 域随机化

| 类别 | 具体 |
| --- | --- |
| 动力学 | 负载 ±5 kg、摩擦系数 0.3–1.0、执行器延迟 0–0.02 s；TRON1 另加 PD 增益/armature ±15% |
| 本体观测噪声 | 线速度 0.1 m/s、角速度 0.2 rad/s、重力投影 0.05、关节位置 0.01 rad、关节速度 1.5 rad/s |
| 地图观测 | 地图值噪声 0.05 m；查询位置漂移 ±0.03 m |
| 学生深度云 | 15% 点缺失 + 2% artifacts |
| 学生地图 | 10% 环境给完整地图（方差 0.0025 m²）；1% 点用随机值 + 大方差（>1 m²）污染 |
| 教师/学生地图 | 两者都注入建图漂移 |

**三点解读**：

1. **随机化是"分层"的**：传感器失真（点缺失/artifacts）与地图失真（漂移/虚假点/完整图）分开注入。
   学生同时吃两种输入，分开才能分别诊断是"传感器坏了"还是"地图坏了"。
2. **10% 环境给完整地图**不是随手写的：它同时服务两个目的——让策略见过"完美图"（不至于过度依赖建图噪声特性），
   以及支持"地图复用"（同一地形重走时用已建好的图，Fig. 5）。
3. **1% 点用大方差随机值污染**是在教策略"看 `u`"：虚假点带高不确定度，若策略无视 `u` 就会被带偏。
   这是把"不确定度通道"从装饰变成可学习信号的必要条件。

**没有随机化的东西**（同样重要）：质量/质心、电机强度曲线（除 TRON1 的 PD/armature 偏置）、地形摩擦的空间分布、
通信延迟。与同类工作比，这里的动力学随机化属于**偏薄**的一档。

**移植到别的机器人时的三个缩放点**：
1. 距离阈值（0.5 m、4 m、2 m）应与机身尺寸/步幅成比例——人形上 0.5 m 可能过宽；
2. `v_max=2 m/s` 与 `cos>0.5` 的锥角要与该机器人的可行速度匹配；
3. 早停阈值（大腿加速度 60/100）依赖腿长与质量分布，直接照搬会过松或过紧。

**一个结构性的观察**：这一节把"安全"拆成了三种机制——终止（硬边界）、正则（软惩罚）、仿真保真（防仿真器伪影）。
三者叠加，使得"策略在仿真里不会学到实机上致命的动作"，而不需要单独的安全层。这也是它能直接跨两种机器人复用的原因。

> 上面是 IV-D 的速记；**奖励项的逐项公式、权重→每步奖励的换算、可翻译成代码的对照表**见本节之后的两节。

# AME-2 逐节精读（七）：奖励函数完整拆解（面向实现）

## 0. 换算规则：怎么从"权重"得到"每步奖励"

这是最容易卡住的一步，因为表 I 的权重**不是每步奖励值**。

### 0.1 表头的含义

表 I 表头是 **"Weight (×dτ*)"**，脚注 **"dτ = 0.02 s is the policy interval"**。含义是：

$$
r_i(t)\;=\;w_i\cdot d\tau\cdot e_i(t)
$$

- `w_i`：表里的权重（单位是"每秒"）；
- `dτ = 0.02 s`：一步的时长；
- `e_i(t)`：该步的**归一化表达式**（核值、掩码、门控、指标值的组合），通常 ∈ [0,1] 或非负。

所以换算分两级：

```
第一级  w  →  w·dτ        得到"该步的基准奖励"（表达式取 1 时）
第二级  ×e(t)             得到"该步实际入账"（要乘核、掩码、门控）
```

### 0.2 为什么要有 ×dτ

因为奖励是**速率**，不是金额。这样写有两个好处：

1. **换控制频率不用改权重**：50 Hz 改 100 Hz，每步奖励自动减半，整回合预算不变；
2. **跨机器人复用**：两个机器人若控制频率不同，同一套权重仍然可比。

副作用：**只要忘了乘 `dτ`，所有奖励会放大 50 倍**（1/0.02），训练行为会完全不同。

### 0.3 一个完整算例（位置项）

$$
r_{\text{pos}}=w\cdot d\tau\cdot k(d)\cdot t_{\text{mask}}(4)
=100\times0.02\times\frac{1}{1+0.25d^2}\times\frac{1}{4}\mathbb 1(t_{\text{left}}<4)
$$

在目标处（`d=0, k=1`）且处在末段窗口内时：

$$
r_{\text{pos}}=100\times0.02\times1\times\frac14=0.5\ \text{/步}
$$

整段窗口（4 s = 200 步）累加：`0.5 × 200 = 100` —— 正好回到 `w × k`。
**两种口径都对，只是问的问题不同**：`w·dτ = 2.0` 是"若不乘掩码的每步值"，`0.5` 是"掩码生效时的每步值"。

### 0.4 每步基准值总表

## 1. 位置跟踪

$$
r_{\text{pos}}=\frac{1}{1+0.25\,d_{xy}^2}\cdot t_{\text{mask}}(4)
$$

`d_xy`：机器人到目标的**水平**距离。

| d (m) | 0 | 0.5 | 1 | 2 | 3 | 4 | 6 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| k | 1.00 | 0.94 | 0.80 | **0.50** | 0.31 | 0.20 | 0.10 |
| 对比 `e^{-0.25d²}` | 1.00 | 0.94 | 0.78 | 0.37 | 0.11 | **0.018** | 1.2×10⁻⁴ |

三个性质：

1. **在 0 处导数为 0**：到点后没有反向梯度，不抖；
2. **代数尾部**：4 m 处仍有 0.20（高斯型只剩 0.018），保证开局 4–8 m 时仍有学习信号；
3. **最大梯度在 d ≈ 1.16 m**：由 $\frac{d}{dd}k=-\frac{0.5d}{(1+0.25d^2)^2}$ 求极值得 $d=\sqrt{4/3}$。
   "拉力"集中在最后 1 米——正是需要精确落脚的区域。系数 0.25 因此不是随手取的：它把半衰点放在 2 m、最大梯度点放在 1.16 m。

**失效模式**：它只测"终态距离"，因此"早到就走开"不吃惩罚——由朝目标移动（近目标恒为 1）与朝向门控兜住。

## 2. 时间掩码

$$
t_{\text{mask}}(T)=\frac{1}{T}\,\mathbb 1(t_{\text{left}}<T)
$$

- 指示函数：只在**回合最后 T 秒**生效；
- `1/T`：预算归一化。末段 T 秒共 `T/dτ` 步，总和 `= w·k`，与 T 无关。

**每步密度的巧合（很可能是设计）**：位置 `w/T = 100/4 = 25`，朝向 `w/T = 50/2 = 25`。
两者每步压力相同（都是 0.5/步），总预算却是 2:1。即**"每步推力相等、总预算不同"**。

## 3. 朝向跟踪

$$
r_{\text{hdg}}=\frac{1}{1+d_\psi^2}\cdot t_{\text{mask}}(2)\cdot\mathbb 1(d_{xy}<0.5)
$$

| d_ψ (rad) | 0 | 0.5 | 1.0 | 1.57 | 3.14 |
| --- | --- | --- | --- | --- | --- |
| k | 1 | 0.80 | 0.50 | 0.29 | 0.09 |

门控 `1(d_xy<0.5)` 的作用：**只在目标附近对齐才给分**。否则机器人可以在远处原地转身刷奖励（那里转身零成本）。
窗口 2 s 比位置项 4 s 短，形成"**先到位、再调头**"的隐含次序。

## 4. 朝目标移动

$$
r_{\text{move}}=\mathbb 1\Big(d_{xy}<0.5\ \lor\ \big(\cos\theta_{\mathbf v,\text{goal}}>0.5\ \land\ 0.3\le\|\mathbf v_{xy}\|\le 2\big)\Big)
$$

- **二值**，不是速度奖励：它是"方向门"，防止策略为刷分而飙速；
- `cos>0.5` ⇒ 速度方向与"指向目标"夹角在 ±60° 内；
- `v_min=0.3`：滤掉噪声与原地微动；
- `v_max=2.0`：**不是机器人极限，而是"感知能承受的上限"**——再快里程计会漂、地图不可信；
- 权重只有 5（0.1/步），作用是**在时间掩码尚未生效时提供稠密梯度**。

## 5. 到点站立

$$
r_{\text{stand}}=\mathbb 1(d_{xy}<0.5\land d_\psi<0.5)\cdot\exp\!\Big(-\frac{d_{\text{foot}}+d_g+d_q+d_{xy}}{4}\Big)
$$

- 门控：到点**且**已对齐；
- 四项归一化偏差：`d_foot`（未接触足数占比）、`d_g = 1−[g_b]_z² = sin²(倾角)`、`d_q`（关节相对站立参考的平均偏差）、`d_xy`；
- 取均值（÷4）后取指数：每 1 单位均值乘 `e^{-1}≈0.37`，**任一项独大都会把奖励压下去**；
- 目的：抑制"到了之后继续踏步/跳跃"，并给出明确终态。

**缺口**：`d_q` 的"站立参考姿态"未定义；双足的"总足数"是否为 2 未写。

## 6. 四项协同

```
时间 ──────────────────────────┤最后4s├──┤最后2s├──►
位置跟踪        ··············■■■■■■■■            0.5/步
朝向跟踪        ····················■■■■ (d<0.5)   0.5/步
朝目标移动      ■■■■■■■■■■■■■■■■■■■■■■■■ (到点后=1)  0.1/步
到点站立        ··················■■■■■■ (到点+对齐)  0.1/步
```

- 前段：只有 moving-to-goal 驱动探索；
- 末 4 s：位置接管；末 2 s：朝向叠加；
- 到点后：站立压住"乱动"。
- 末段瞬时最大总奖励 ≈ **1.2/步**。

## 8. 早停到底是 −10 还是 −500（必须查代码）

表头约定 **项值 = 权重 × dτ × 表达式**，而早停权重写成 `−10/dτ`：

$$
\Big(-\frac{10}{d\tau}\Big)\cdot d\tau\cdot 1=-10
$$

**写成分式正是为了让惩罚与控制频率无关**，因此更可能是一次性 `−10`。

| 读法 | 结果 | 后果 |
| --- | --- | --- |
| 按表头乘 dτ | **−10** | 一次摔倒 ≈ 20 步满分位置奖励，常见量级 |
| 按字面不乘 dτ | −500 | ≈ 整回合位置预算的 5 倍，策略极度保守 |

同理"不良事件 −1/次"是否也乘 dτ（→ −0.02）需一并确认。**这是复现时第一个应该对着 `rewards.py` 核的数值。**

# 附录 B：为什么正则项的权重那么小——原理，还是经验？

**结论：一半原理，一半经验。** 原理决定"必须有 1–2 个数量级的差距"，经验决定"具体落在哪个幂次"。

## 1. 原理部分：这是罚函数法，不是多目标加权

任务奖励定义"**做什么**"，正则项定义"**不许以什么方式做**"。后者是可行性约束，不是第二个目标。
在罚函数框架里，系数 λ 有一个窗口：

- **下界**：λ 要大到让"违规带来的任务收益"变成负的；
- **上界**：λ 要小到不改变最优任务解——否则策略会牺牲任务去满足约束。

RL 里没有解析的 λ*，只能靠**量级差**保证落在窗口内。1–2 个数量级就是这个经验窗口的宽度。

## 2. 为什么不能大：退化解

如果正则项与任务项同量级，最优策略会变成"**站着不动**"：

$$
\dot q=0,\ \tau\text{ 小},\ \Delta a=0,\ F_{con}=0,\ \omega=0\ \Rightarrow\ \text{所有惩罚项为 0}
$$

任务奖励拿不到，但惩罚全免。这是足式 RL 里最经典的失败模式（策略"学会不动"）。
所以小权重不是审美偏好，而是**防退化解的结构性要求**。

## 3. 为什么取 10 的整数幂

1. **绝对数值没有物理意义**，只有相对量级有意义；
2. **粗网格**：调一个数量级就能显著改变行为，避免在 1.3 vs 1.5 之间做无意义搜索；
3. **便于消融与跨机器人复用**：作者正是用"两个机器人共用同一套权重"来论证"不需要大量调参"。

## 4. 系数有时是量纲换算，不是重要性权重

关节正则三项混量纲：`‖q̇‖²`（rad²/s²）、`0.01‖τ‖²`（N²m²）、`0.001‖q̈‖²`（rad²/s⁴）。代入典型步态值：

| 项 | 典型值 | 贡献 |
| --- | --- | --- |
| `‖q̇‖²` | `q̇≈5 rad/s` | 25 |
| `0.01‖τ‖²` | `τ≈20 Nm` | 4 |
| `0.001‖q̈‖²` | `q̈≈100 rad/s²` | 10 |

0.01 的作用是把 `400` 压到 `4`——**它首先是单位换算，其次才是"力矩项不太重要"的表达**。
不这么做，力矩项会完全主导（400 : 25）。

## 5. "小"不是普适规则：三层结构

| 层 | 惩罚量级（每步） | 性质 | 违反后果 |
| --- | --- | --- | --- |
| 风格/平滑（动作平滑、link 加速度、横滚角速度） | 10⁻³~10⁻⁵ | 偏好，可以违反 | 动作糙、抖 |
| 硬件保护（接触力超重、关节速度/力矩限幅） | 10⁻³~10⁰ | 不应违反 | 磨损、寿命 |
| 物理保真（关节位置限幅 −1000） | 10¹ | **绝不能违反** | 仿真不可信，学到的全作废 |

仿真保真项比其它正则大 3–6 个数量级，正因为它的性质不同：它不是"风格"，而是"**仿真器在极限附近会输出非物理行为**"，
一旦策略学会利用这种伪影，sim2real 直接崩。所以这里的罚函数必须"一步越界就抵消整段任务收益"。

## 6. 小权重的代价：必须有硬边界兜底

正则太软意味着约束会被违反。这正是"**软惩罚 + 硬终止**"组合存在的原因：
大腿加速度、姿态翻转、基座碰撞都用**终止**而不是奖励——因为要用奖励实现同等强度，权重必须大到毁掉任务学习。

## 7. 经验 vs 原理的界线

| 属于原理 | 属于经验 |
| --- | --- |
| 罚函数需要量级窗口 | 具体落在 10⁻² 还是 10⁻³ |
| 量纲必须归一 | 0.01 / 0.001 这两个系数 |
| 过大导致退化解 | 95% / 90% / 80% 三个余量 |
| 保真项必须显著大于风格项 | 具体大 3 个数量级还是 4 个 |
| 软惩罚需要硬边界兜底 | 阈值取 60 / 100 m/s² |

**证据强度**：作者用"跨两个机器人共用"作为鲁棒性的证据，但两台机器人都由同一团队调参，外部效度有限。
换到第三个机器人（如人形 G1）时，第 5 节的三层结构可以照搬，**具体幂次必须重标**。

## 8. 与 PPO 的交互

- 奖励 O(1)/步、`γ=0.99` ⇒ 回报 O(100)，价值网络拟合尺度合适；
- 若正则也 O(1)，回报被罚项主导，价值估计方差上升；
- PPO 的 advantage 归一化只消除**整体尺度**，不改变**项间相对权重**——所以相对量级才是真正要设计的东西。

# AME-2 逐节精读（八）：IV-E Training and Deployment

三小节：训练配置（框架、迭代、成本、地图尺寸）、部署（ONNX、耗时）、其他 sim-to-real 设计（执行器模型、命令不对称）。

## 1. 训练配置

| 项 | 值 |
| --- | --- |
| 框架 | Isaac Gym + RSL-RL 的 PPO |
| 教师迭代 | 80 000 |
| 学生迭代 | 40 000（前 5 000 次关 surrogate loss） |
| 成本（ANYmal-D） | 约 60 RTX-4090-day，8 卡并行 |
| 成本（TRON1） | 约 30 RTX-4090-day，4 卡并行 |
| 地图（ANYmal-D） | 36×14，8 cm，中心 `(0.6, 0)` m |
| 地图（TRON1） | 18×13，8 cm，中心 `(0.32, 0)` m |

### 1.1 成本与地图尺寸的关系（一个可验证的算术）

两台机器人的**墙钟时间相同**（60/8 = 30/4 = 7.5 天），GPU-day 之比 2:1。
而地图点数之比 504 : 234 ≈ 2.15 : 1。

**结论：训练成本近似与地图点数成正比。** 说明瓶颈在"按点数线性增长"的那部分（编码器与注意力），
而不是固定开销（物理仿真）。这对复现很实用：换地图尺寸可以直接按点数估算算力。

### 1.2 "迭代"的含义要小心

附录 C 给了：每轮 24 个仿真步、4 个 epoch、3 个 minibatch、4800 环境。于是

$$
\text{教师总步数}=80{,}000\times24\times4800\approx9.2\times10^{9}
$$

学生约 `4.6×10^9`。**"80000 iterations" 不是 80000 个回合**，差三个数量级。
若按回合数理解，会把训练量估错上千倍。

按 60 GPU-day 摊，约 2 700 环境步/秒（8 卡合计，≈330/卡）——这个数字可以用来判断自己的吞吐是否正常。

### 1.3 地图的物理尺寸

| 机器人 | 栅格 | 物理范围（base frame） |
| --- | --- | --- |
| ANYmal-D | 36×14 @8 cm | x ∈ [−0.84, 2.04] m，y ∈ [−0.56, 0.56] m |
| TRON1 | 18×13 @8 cm | x ∈ [−0.40, 1.04] m，y ∈ [−0.52, 0.52] m |

**这是一个非常局部的地图**（前方约 2 m）。它说明"泛化"指的是对**局部几何**的泛化，
而不是全局导航能力。也解释了为什么必须靠"建图在环 + 地图复用"获得长时信息。

## 2. 部署

- ONNX Runtime；i7-8850H 上策略推理约 **2 ms**。
- 加上建图的 5 ms/帧，合计约 7 ms，占 50 Hz 周期（20 ms）的 35%，剩约 13 ms 给 SLAM 与底层控制。

**这个预算表比任何文字都更能说明"为什么建图必须轻"**：端到端大模型（哪怕 20 ms）会把整机预算吃光。

## 3. 其他 sim-to-real 设计

### 3.1 执行器建模

- ANYmal-D：执行器网络（辨识得到）；
- TRON1：辨识的直流电机模型；
- 力矩按"力矩–转速包络"裁剪。

两种机器人用两套模型，说明这套框架**不假设统一执行器**，而是把执行器当作可替换模块。

### 3.2 命令观测的不对称（本节最值得学的一处）

| 角色 | 拿到的命令 |
| --- | --- |
| critic | 完整：目标相对位置、相对偏航的 sin/cos、**剩余回合时间** |
| actor | 距离**截断到 2 m**、**去掉剩余时间**；且若真实距离 > 2 m，训练时**随机化偏航命令** |

三个设计意图：

1. **去掉剩余时间** → 消除"回合时钟"这种实机上不存在的量，使策略天然支持无限时运行；
2. **截断距离到 2 m** → 防止策略学到"距离 → 还需多久/该多快"的捷径；超过 2 m 时观测饱和，
   策略只知道"还远"，不知道该多远；
3. **远距随机化偏航** → 远处时朝向指令无意义（先得走过去），随机化迫使策略形成"先接近、后对齐"的两段行为。

**这是一个纯"接口重设计"的 sim2real 方案**：不加模块、不做域随机化，只改观测的定义。
代价是：距离 > 2 m 时观测饱和，策略在"2 m 边界"附近的行为是模糊的——靠奖励里的 moving-to-goal 兜住。

# 附录 D：为什么要截断距离、去掉剩余时间

## 1. 时钟是训练特有的量

训练时回合有固定长度，策略能看到 `t_left`。有了它，策略可以学"还剩 3 s、距离 2 m ⇒ 该加速"这类**时间-距离调度**。
部署时没有回合概念（无限时运行），`t_left` 不存在。依赖它的策略会直接掉出训练分布。

这与"actor 不能拿实机上不存在的量"是同一条原则：**决策用的观测里不放部署不可用的信息**。

## 2. 距离本身是时钟的代理

即使去掉 `t_left`，**绝对距离也隐含"这是第几秒"**：起点距离分布固定、回合长度固定，
于是"距离 4 m"几乎只出现在回合早期，"距离 0.5 m"只出现在晚期。
策略可以把距离当成进度计，学出"早段慢、晚段快"的固定节奏，而不是"按地形决定速度"。

## 3. 截断到 2 m 正好破坏这个映射

截断后，所有 >2 m 的距离都显示为 2 m。策略**无法区分"刚出发"与"走了一半"**，
只能学到"看到 2 m 就朝目标移动"——也就是最基础、最可迁移的行为。
2 m 这个数不是随便选的：它等于位置奖励核的半衰点（`1/(1+0.25d²)` 在 2 m 处 = 0.5）。

## 4. "该多快"由奖励规定，不由距离推断

moving-to-goal 已经用 `0.3 ≤ v ≤ 2 m/s` 的带规定了速度区间。若策略再从距离自行推断速度，
两套规则会打架，容易产生加速-减速振荡。**把速度决策交给奖励、把决策输入里的速度线索拿掉**，是更干净的划分。

## 5. 远处随机化偏航：把"导航"与"对齐"解耦

目标在 2 m 外时，朝向指令几乎无意义（先得走过去，方向随时在变）。训练时随机化 yaw，
等于告诉策略"远处别信这个指令"，迫使它形成两段式行为：**先接近，靠近后再用朝向对齐**。
这也解释了奖励里为什么位置窗口 4 s、朝向窗口 2 s——与两段式行为同构。

## 6. 为了"任意远的目标"

训练时起点平均 4 m，部署时用户可能给 20 m 外的目标。若策略依赖距离绝对值，超出训练范围即失效；
截断后"远"变成一个**饱和类别**，天然可外推到任意距离——靠"走一段、重规划一段"完成。

## 7. 代价

- 距离 >2 m 时观测饱和，策略分不清 2 m 与 10 m，接近阶段可能速度保守；
- 2 m 边界附近观测有饱和拐点，行为可能不连续，需要奖励平滑兜住；
- 论文的成功率评估起点在 4 m 内，**恰好绕开了这个弱点**——评估协议没有覆盖"很远的目标"。

## 8. 与"信息集分层"同源

critic 拿 `t_left`、拿完整距离，是**因为价值估计需要知道还剩多少奖励预算**；
actor 不拿，是因为**决策不需要、且会污染**。
同一个量，对价值是必要信息，对策略是噪声——这是非对称 AC 的一个精确用法，而不只是"特权信息随便给 critic"。

# AME-2 逐节精读（九）：V-A Mapping Pipeline

这是全文最原创的一节。控制器那部分是"给已有结构加一个输入"，建图这部分是**重新定义融合的概率语义**。

## 1. 五步流程

```
① 深度点云 ──投影──► 局部 2D 高程栅格（同格取 max z；空格填固定最小值）
② 轻量 CNN ──► 相对基座的高程 μ + 对数方差 log σ²
③ 里程计位姿 ──► 把局部预测写入全局栅格 M（两层：高程 + 方差）
④ 逐格 Probabilistic Winner-Take-All 融合（三个机制，见 §3）
⑤ 查询机器人周围局部栅格 ──► 控制器
```

【原文】这一节开宗明义两件事：**实时**（硬件上算得动）与**可并行**（仿真里上千环境），
两者同时成立才叫"训练分布 = 部署分布"，这是全文 sim2real 论证的地基。

## 2. 每一步的细节与设计意图

### 步骤 ①：投影到局部栅格

- 同一格内有多个点时**取最大 z**：对足式运动而言"最高面"才是可踩的面（地面 vs 台阶顶面）；
- **无点的格子填一个固定最小值**——不是 NaN，也不是空白。
  这是把"没有数据"编码成一个**可被卷积处理的值**，网络必须自己从上下文学到"这个格子其实是缺测"。
- 后果：空缺格在输入图里看起来像"深坑"。这正是为什么网络需要输出**不确定度**——
  否则它无法区分"真的是坑"与"只是没测到"。

### 步骤 ②：网络输出"相对基座的高程"与"对数方差"

- 输出是**base-relative** 高程（相对机器人基座），不是世界高度 ⇒ 与机体姿态解耦，便于策略直接使用；
- 不确定度以 **log 方差** 形式输出（数值稳定，且天然保证正定）；
- 【原文】预测出的不确定度**同时覆盖测量噪声与遮挡**；高程预测本身也起去噪作用。

### 步骤 ③：全局图（两层）与初始化

- 全局图 `M` 有两层：高程层 + 方差层；
- **初始化为"机器人站立高度的平地" + 大方差**。

【解读】这个初始化值得单独说：未观测区域的**初值**是"平地"，而不是空的。
所以地图在任何时刻都是"完整"的（没有空洞），但未知区域带着大方差。
这与"用学到的先验补全遮挡"（论文批评的做法）有本质区别：**这里是几何先验 + 显式不确定度，不是网络幻觉**。
不过代价是：如果策略无视 `u`，它会把未知区域当成平地——这就是为什么训练里要注入高方差虚假点。

### 步骤 ④：融合（下一节详述）

### 步骤 ⑤：查询

- 从最新全局图里按机器人位姿取出局部栅格给控制器；
- 【存疑】控制器的图是 8 cm、建图局部栅格是 4 cm，重采样方式（取最近邻？取最大？带方差如何合并）未写。

## 3. 融合律：三个机制，各治一个病

记先验 $(h_{\text{prior}},\sigma_{\text{prior}}^2)$、本帧观测 $(h_t,\sigma_t^2)$。

### 机制一：方差下限（限速器）

$$
\hat\sigma_t^2=\max\!\big(\sigma_t^2,\ 0.5\,\sigma_{\text{prior}}^2\big)
$$

【解读】它限制"单帧最多让精度翻倍"。若观测极准，`σ̂²` 被抬到 `0.5σ_prior²`，
于是单次更新最多把方差减半——**方差按几何级数下降，k 次接受更新后 ≤ `2^{-k}·σ_prior²`**。
这防的是"一帧就把某个格子钉死"。

### 机制二：有效性门（拒绝变差）

$$
\text{valid}\iff \hat\sigma_t^2<1.5\,\sigma_{\text{prior}}^2\quad\text{或}\quad \hat\sigma_t^2<0.2^2
$$

- 前一条：**观测不能明显差于先验**（>1.5 倍方差即拒绝）；
- 后一条：**绝对精度够好就无条件接受**（σ < 20 cm）。这一条允许"高置信的新观测"改写已经很确定的旧图，
  也是"能快速响应地形变化"的来源。
- 注意量纲：`0.2² = 0.04 m²`，即 20 cm 标准差——约等于 5 个建图栅格（4 cm）或 2.5 个策略栅格（8 cm）。

【解读】**这一条才是"遮挡不会被虚降方差"的真正原因**：遮挡处的预测方差大，`σ̂² ≥ 1.5σ_prior²`，
且通常 `σ̂² ≥ 0.04`，于是被直接拒绝，该格永远保持旧值与旧方差。
前面那条"下限"只是限速，不是决定性机制。

### 机制三：按精度加权的随机覆盖

$$
p_{\text{win}}=\frac{(\hat\sigma_t^2)^{-1}}{(\hat\sigma_t^2)^{-1}+(\sigma_{\text{prior}}^2)^{-1}}
=\frac{\sigma_{\text{prior}}^2}{\hat\sigma_t^2+\sigma_{\text{prior}}^2}
$$

$$
(h_{\text{new}},\sigma_{\text{new}}^2)=
\begin{cases}
(h_t,\hat\sigma_t^2) & \xi<p_{\text{win}},\ \xi\sim\mathcal U[0,1]\\
(h_{\text{prior}},\sigma_{\text{prior}}^2) & \text{otherwise}
\end{cases}
$$

### 数值行为（由机制一与三可以算出）

| `σ_t² / σ_prior²` | `σ̂²/σ_prior²`（截断后） | `p_win` | 说明 |
| --- | --- | --- | --- |
| 0.1 | 0.5 | **0.667** | 极准的观测也只能拿 2/3 |
| 0.5 | 0.5 | **0.667** | 上限 |
| 1.0 | 1.0 | 0.500 | 同等置信 |
| 1.5 | 1.5 | 0.400 | 临界，刚好不满足 `<`，**无效** |
| 2.0 | 2.0 | 0.333 | 除非 `σ̂²<0.04`，否则无效 |

**两个直接推论**：

1. **单帧最大覆盖概率是 2/3**。连续 k 帧独立采样，至少覆盖一次的概率是 `1−(1/3)^k`：
   3 帧 ≈ 96%，5 帧 ≈ 99.6%。所以一个真正好的观测**需要 2–3 帧**才能改掉一个已建立的格子——这是"慢性子"设计，
   与"敏捷"的表象相反，但对地图稳定性是必要的。
2. **被拒帧不消耗任何东西**：无效更新直接返回，`h` 与 `σ²` 都不变。所以"很多帧无效"在计算上很便宜。

## 4. 为什么是 Winner-Take-All，而不是卡尔曼/贝叶斯

| 维度 | 标准贝叶斯（卡尔曼式） | 本文 WTA |
| --- | --- | --- |
| 更新方式 | 加权平均：`h←h+K(z−h)` | **整值覆盖**（不平均） |
| 方差 | 每次观测必降（单调） | 有下限、有门控，可长时间不变 |
| 遮挡 | 越看越"确定"（危险） | 保持高方差（诚实） |
| 高度不连续处（台阶边、箱角） | 两个高度的点被平均 → **边缘被抹平** | 保留其中一个 → **边缘锐利** |
| 动态地形 | 被历史平均拖住 | 高置信观测一帧即可改写 |

【解读】第 4 行是我认为最被低估的优点：**平均会毁掉台阶边缘**。
足式运动恰恰依赖边缘（近边缘落脚、梁宽判断），所以"不平均"不是工程妥协，而是**为任务服务的**。
代价是地图更吵（没有多帧平均去噪），因此去噪被前移到了网络的推断里（步骤 ② 的 CNN）。

## 5. 原文给的四条好处

1. 同一遮挡点的不确定度**不会因为预测一致而下降**；
2. **过度自信的预测无法覆盖**已有地图（除非它同时满足绝对精度门）；
3. 有高置信测量时，系统能**快速更新**以响应动态地形；
4. 易与并行仿真集成、足够快。

四条与三个机制一一对应：1↔机制二，2↔机制一+二，3↔机制二的后半句，4↔整条管线只用逐格运算。

## 7. 与 ACP 的关系

ACP 的 LiDAR 建图**沿用了整条融合律**，只做两处改动：

1. 网络从"回归高程 + 方差"改成**三模式分类**（保留测量 / 邻域均值 / 丢弃），mode logits 的分歧当不确定度——
   因为 LiDAR 是稀疏全景、不是稠密深度；
2. 融合里加一条**悬垂结构先验**：当新预测落在已有置信格（`σ<0.15 m`）上且低于它 0.15 m 以上时，
   除非仰角 > −40°，否则**丢弃**——防止"后看的近处地面"把"先看到的梯子横档"擦掉。

也就是说，AME-2 的 WTA 在 ACP 里是**被完整继承的第一个模块**，只加了针对悬垂的补丁。

# 附录 E：三个常见误解

## E1 "点云投影完不就已经得到高程了吗，为什么还要 CNN？"

**投影得到的是"测量"，不是"高程估计"。** 两者之间差着一个估计器。

传统高程建图里这一步确实存在，只是用手工算子写的：

```
点云 → 投影到栅格（同格取 max z）→ 中值/双线性滤波 → 腐蚀/膨胀 → 缺测插值 → 可用高程
```

本文把这串手工算子换成**一个网络**。原因是原始投影有五个性质，手工滤波处理不好：

| 问题 | 表现 | 手工做法的困境 |
| --- | --- | --- |
| **稀疏** | 远处点少、相机 FOV 外无数据，51×31 里常有一半空 | 插值无法区分"真平地"与"没测到" |
| **噪声** | 深度相机在反光、弱纹理、边缘处噪声大 | 固定核滤波无法随场景自适应 |
| **遮挡** | 被挡住的区域**没有点**，偶有杂点落入 | 单帧滤波会把杂点当真值 |
| **边缘混合** | 台阶边缘一格内同时有顶面与侧面点，取 max 会"抬高"边缘 | 形态学算子会削掉锐利边缘 |
| **姿态** | 投影点在传感器系，需变换到基座系；姿态噪声直接变成高度噪声 | 无法建模姿态不确定性 |

所以：**投影给出 z，CNN 给出 (h, σ)**——去噪、在遮挡处按上下文补全（同时输出大方差承认是猜的）、
并把高度统一到基座系。它不是"从点云重建高程"，而是"把粗糙的逐格测量精化成带置信度的估计"。

## E2 CNN 的输入到底是什么

**输入**：投影得到的局部高度图。

- 单通道（高度值），尺寸 51×31（ANYmal-D）/ 31×31（TRON1），分辨率 4 cm；
- 空格填**固定最小值**（不是 NaN）——网络靠数值本身区分"缺测"；
- 【存疑】是否额外拼一个"有效位掩码"通道，正文未写。

**输出**：三个头（图 8）

```
h_raw  : 1×1 conv
log σ² : 1×1 conv
β      : 1×1 conv + sigmoid
h_out  = β ⊙ h_raw + (1−β) ⊙ h_in        ← 门控混合输入与净估计
```

**结构**：`2×conv(16, 3×3) → maxpool(3, stride 3) → 2×conv(16, 3×3) → concat → upsample → 1×1 头`。
只有一个下采样层级，刻意做浅——因为要满足 `< 0.3 ms × 1000 环境`。

**训练输入不是真实深度**，而是从地形 mesh 光线投射出的合成局部高程（再叠加噪声、遮挡、裁剪等增广）。
网络学的是"从带噪缺测的高程图恢复真值"，真实传感器噪声靠增广模拟。

## E3 "传统贝叶斯融合"是什么？fast-lio 会做吗？

### 先分清两种"贝叶斯"

| | 表示 | 融合对象 | 用在哪 |
| --- | --- | --- | --- |
| 占用栅格（log-odds） | 每格一个占据概率 | 二值"有/无" | 2D 导航、避障 |
| **高程栅格（高斯）** | 每格 `h ± σ²` | 连续高度 | **足式高程建图** |

本文说的"标准贝叶斯融合"是**后者**。

### 高程图里的贝叶斯融合 = 逐格卡尔曼

给定先验 $(h_p,\sigma_p^2)$ 与本帧测量 $(z,\sigma_m^2)$：

$$
K=\frac{\sigma_p^2}{\sigma_p^2+\sigma_m^2},\qquad
h\leftarrow h_p+K(z-h_p),\qquad
\sigma^2\leftarrow(1-K)\sigma_p^2=\frac{\sigma_p^2\sigma_m^2}{\sigma_p^2+\sigma_m^2}
$$

等价的信息形式（更直观）：

$$
\frac{1}{\sigma^2}=\frac{1}{\sigma_p^2}+\frac{1}{\sigma_m^2},\qquad
h=\frac{\sigma_p^{-2}h_p+\sigma_m^{-2}z}{\sigma_p^{-2}+\sigma_m^{-2}}
$$

"**精度相加**"就是这一步：两次**独立**观测的方差倒数相加。高斯假设 + 独立假设的直接结果。

这套做法在足式高程建图里是标准配置（论文 Related Works 引的两篇即代表）：
- Fankhauser 等，*Probabilistic terrain mapping for mobile robots with uncertain localization*——并把机器人位姿不确定度传播进每格；
- Miki 等，*Elevation mapping … using GPU*——同一套融合搬到 GPU 跑到高频。

### fast-lio 不做这个

FAST-LIO / FAST-LIO2 是**激光-惯性里程计**：把每帧点云按估计位姿变换后插入 ikd-Tree，
优化的是**位姿**（点到面残差），地图是**点云**——`map` 里没有"每格高度 ± 方差"。

- **传统 LiDAR SLAM 本体：没有逐格高度贝叶斯融合。**
- **传统 SLAM 生态里的高程建图模块（elevation_mapping / grid_map）：有，且就是卡尔曼式。**
- 论文对比的对象是后者，不是在否认 LiDAR SLAM。

### 为什么这套在这里会坏

【原文】"对同一块被遮挡的区域反复观测，不该因为预测一致就降低不确定度"。用信息形式看最清楚：

连续 N 帧对同一遮挡格给出"一致的"预测、每帧方差 `σ_m²`，若把它们当作独立观测：

$$
\frac{1}{\sigma_N^2}=\frac{1}{\sigma_0^2}+\frac{N}{\sigma_m^2}\ \Longrightarrow\ \sigma_N^2\to\frac{\sigma_m^2}{N}
$$

**N=10 帧、σ_m = 2 cm ⇒ σ_N ≈ 0.63 cm**：地图会以 6 mm 的置信度相信一个从未真正看到过的地方。
而这些帧高度相关（同样遮挡、同样网络、同样缺失数据），独立假设完全失效。

三个附加问题：**方差单调下降**（无法表达"我一直没看到"）、**加权平均抹平高度不连续处**（台阶边缘）、
**响应动态地形慢**（被历史平均拖住）。

### WTA 与卡尔曼的真实关系（一个精确对照）

把 `p_win` 写开：

$$
p_{\text{win}}=\frac{(\hat\sigma_t^2)^{-1}}{(\hat\sigma_t^2)^{-1}+(\sigma_p^2)^{-1}}
=\frac{\sigma_p^2}{\hat\sigma_t^2+\sigma_p^2}
$$

**这就是卡尔曼增益 `K`。** 所以 AME-2 并没有抛弃"按精度加权"，而是把 `K` 的角色从
"**平均时的权重**"改成"**整值覆盖的概率**"。

| | 卡尔曼 | 本文 WTA |
| --- | --- | --- |
| 期望值 | `h_p + K(z−h_p)` | `E[h] = p h_t + (1−p) h_p = h_p + K(h_t−h_p)`——**期望相同** |
| 实现 | 直接取期望（平均） | 采样一个结果（保留整值） |
| 方差 | `(1−K)σ_p²`，必然下降 | `σ_new² = σ̂_t²`，**可能上升** |

第三条最反直觉：若 `σ_m² = 1.4σ_p²`（仍满足有效性门），更新后方差变成 `1.4σ_p² > σ_p²`——
**一次"可信但更差"的观测会让地图更不确定**。这在贝叶斯里不可能，在 WTA 里是刻意保留的性质：
置信度由观测质量决定，而不是"看得次数多就自信"。

而"保留整值不取平均"，正是为了**不抹掉台阶边缘**——为足式任务付的代价，值。

# 附录 F：卡尔曼滤波快速复习

## 1. 一句话

卡尔曼滤波 = 在"**高斯 + 线性 + 独立**"三个假设下，把"预测"和"观测"按**精度**（方差倒数）加权平均的递推。

## 2. 标量情形（高程图每格就是一个标量 KF）

先验 $x\sim\mathcal N(\mu^-,\sigma_-^2)$，观测 $z=x+v,\ v\sim\mathcal N(0,\sigma_m^2)$。
后验是两个高斯相乘：

$$
\mathcal N(\mu^-,\sigma_-^2)\cdot\mathcal N(z,\sigma_m^2)\ \propto\ \mathcal N(\mu^+,\sigma_+^2)
$$

指数配方（把二次型配成完全平方）得到：

$$
\frac{1}{\sigma_+^2}=\frac{1}{\sigma_-^2}+\frac{1}{\sigma_m^2},
\qquad
\mu^+=\sigma_+^2\Big(\frac{\mu^-}{\sigma_-^2}+\frac{z}{\sigma_m^2}\Big)
$$

引入增益 $K$ 形式：

$$
K=\frac{\sigma_-^2}{\sigma_-^2+\sigma_m^2},\qquad
\mu^+=\mu^-+K\,(z-\mu^-),\qquad
\sigma_+^2=(1-K)\sigma_-^2=\frac{\sigma_-^2\sigma_m^2}{\sigma_-^2+\sigma_m^2}
$$

**这就是"精度相加 + 按精度加权平均"的全部内容。**

## 3. 增益 K 的四种读法

| 读法 | 表达 |
| --- | --- |
| 精度比 | `K = Λ⁻ / (Λ⁻ + Λ_m)`，其中 `Λ = 1/σ²` |
| 加权 | `μ⁺ = (1−K)μ⁻ + K z` |
| 极限 | `σ_m→0 ⇒ K→1`（全信观测）；`σ_m→∞ ⇒ K→0`（全信先验）；相等 ⇒ `K=0.5` |
| 新息系数 | `z−μ⁻` 是"新息"，K 是"新息该信几分" |

附：K 也是最小二乘意义下的最优系数（正交原理 `E[(x−μ⁺)(z−μ⁻)]=0`）。

## 4. 方差的两个铁律

1. **后验不比任何一个输入更差**：`σ_+² ≤ min(σ_-², σ_m²)` —— 这就是"方差单调下降"的来源；
2. **信息量可加**：`Λ⁺ = Λ⁻ + Λ_m`。于是 `N` 次同方差独立观测 ⇒ `σ²/N`。

## 5. 高程建图里的具体形态

- 状态：每格一个标量高度（**假设格与格独立**）；
- 观测矩阵 `H = 1`（观测直接就是该格高度）；
- 位姿不确定度传播（Fankhauser 那篇的做法）：

$$
\sigma_m^2 \leftarrow \sigma_{\text{sens}}^2+\mathbf J\,\Sigma_{\text{pose}}\,\mathbf J^\top
$$

- 预测步几乎恒等（地形不变），所以常常只写更新步——这正是为什么很多实现看起来"没有预测步"。

## 6. 多变量版本（复习用）

$$
\begin{aligned}
&\text{预测：}& \mathbf x^-&=\mathbf F\mathbf x+\mathbf B\mathbf u, & \mathbf P^-&=\mathbf F\mathbf P\mathbf F^\top+\mathbf Q\\
&\text{更新：}& \mathbf K&=\mathbf P^-\mathbf H^\top(\mathbf H\mathbf P^-\mathbf H^\top+\mathbf R)^{-1}\\
& & \mathbf x^+&=\mathbf x^-+\mathbf K(\mathbf z-\mathbf H\mathbf x^-), & \mathbf P^+&=(\mathbf I-\mathbf K\mathbf H)\mathbf P^-
\end{aligned}
$$

数值上 `P⁺=(I−KH)P⁻` 易失去对称正定，工程上多用 Joseph 形式：
`P⁺=(I−KH)P⁻(I−KH)ᵀ+KRKᵀ`。

## 7. 三个假设怎么坏

| 假设 | 破坏方式 | 典型后果 |
| --- | --- | --- |
| 高斯 | 一格内有多个表面（台阶侧+顶面）、遮挡 | 单峰后验无法表达，均值落在两表面之间 |
| 线性 | 投影/取 max/栅格化都是非线性 | 需 EKF/UKF，或干脆不建概率模型 |
| **独立** | 同一传感器连续帧高度相关 | **信息量虚增，σ²→σ²/N**，自信地错 |

第三条是 AME-2 的攻击点。应对方式有四种：

1. 不做时序滤波（每帧重建）；
2. 给过程噪声 `Q` 设下限，防止方差无限下降；
3. **限制单次更新的信息增益**——AME-2 的 `σ̂² ≥ 0.5σ_prior²` 本质就是"给 Q 设下限"，保证单帧最多精度翻倍；
4. 不做加权平均（改成采样覆盖 / WTA），避免把相关样本平均进去。

## 8. 与 AME-2 的精确对应

- `p_win` = 卡尔曼增益 `K`（精度比）；
- 但方差更新**不**用 `(1−K)σ_-²`，而是直接取截断后的测量方差 `σ̂²` ⇒ 方差可能**上升**；
- 且用"采样覆盖"代替"取期望" ⇒ 保留锐利边缘，代价是地图更吵。

## 9. 四道自测

| # | 题 | 答案 |
| --- | --- | --- |
| 1 | 先验 σ=2、观测 σ=2，求 K 与后验 σ | K=0.5，σ⁺=√2≈1.41 |
| 2 | 先验 σ=1、观测 σ=3，求 K | K=1/(1+9)=0.1 |
| 3 | 观测极准/极差时 K 的极限 | 1 / 0 |
| 4 | 10 次同方差独立观测后 σ 变成几倍 | `1/√10 ≈ 0.32` 倍 |
